### U02 — create `packages/element/src/textStyleRanges.ts` (codegen)

Behaviour: Pure styled-range model: normalise, apply a style, diff and shift on edits, sanitise, clamp, map ranges onto wrapped lines and lay out runs.

Rules:
1. 1. No DOM, React or measurement imports; the only imports are `import type { ExcalidrawTextElement, TextAlign, TextStyleRange } from "./types";`. Every function returns new arrays and never mutates its inputs.
2. 2. A colour value counts as present only when it is a non-empty string; output range objects have the keys start and end, plus color and highlight only when present (never a key holding undefined).
3. 3. normalizeStyleRanges: clamp start and end into [0, textLength], drop ranges with start >= end or with no colour present; resolve overlaps with a sorted boundary sweep where, on each elementary segment, ranges later in the input override each property they define; drop segments with no property; merge neighbours where a.end === b.start and color and highlight are equal; return sorted by start.
4. 4. applyTextStyle: clamp [start, end) into [0, textLength] and return the normalised input unchanged when empty; otherwise keep each normalised range's parts outside the span as they are, and on its part inside the span set each style key whose value is a string and delete each key whose value is null (undefined keys untouched); fill uncovered gaps inside the span with a new range holding the style's string values (none when it has no string value); return the normalised result.
5. 5. diffText: p = length of the common prefix; s = length of the common suffix, capped at min(prev.length, next.length) - p; returns null when the strings are equal, else { from: p, to: prev.length - s, insertLength: next.length - s - p }.
6. 6. shiftStyleRanges maps each range with delta = insertLength - (to - from): start' = start < from ? start : start >= to ? start + delta : from + insertLength; end' = end <= from ? end : end >= to ? end + delta : from; so text inserted strictly inside a range takes its style and text inserted at a range boundary does not; then normalise against nextTextLength (callers may pass Number.POSITIVE_INFINITY).
7. 7. getStyledLines: split `text` on "\n" and walk a pointer p through originalText; before every line after the first, step over one "\n" if originalText[p] is "\n", otherwise skip whitespace other than "\n" until originalText.startsWith(line, p); a line found at p covers [p, p + line.length) and is cut into runs at range boundaries, each run { text, start, color, highlight } taking the covering range's values or null; a line not found at p becomes one unstyled run and p advances by its length; an empty line gives [].
8. 8. getStyledRunPositions: total = sum of widths; lineLeft = 0 for left, (boxWidth - total) / 2 for center, boxWidth - total for right; left to right x[i] = lineLeft + sum(widths[0..i-1]); when rtl x[i] = lineLeft + total - sum(widths[0..i]).
9. 9. getUniformRangeStyle returns the property's value when every offset of the clamped [start, end) is covered by normalised ranges with that same present value, else null (also null for an empty span).
10. 10. sanitizeStyleRanges: non-array gives null; keep only entries that are objects with Number.isInteger start and end; keep color/highlight only when non-empty strings; drop entries left with no colour; normalise against textLength; an empty result gives null.
11. 11. getStyleRangesClampUpdate returns {} when the element has no ranges or normalizeStyleRanges(ranges, textLength) is equal per areStyleRangesEqual, else { styleRanges: <normalised> }.
12. 12. areStyleRangesEqual compares length and each range's start, end, color and highlight in order.
