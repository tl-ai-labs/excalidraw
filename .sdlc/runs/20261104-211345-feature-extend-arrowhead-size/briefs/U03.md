### U03 — edit `packages/element/src/bounds.ts` (codegen)

Behaviour: Scales every arrowhead of an element by its arrowheadSize before the short-segment fitting, makes a large-headed arrow's bounds (and so its export frame) contain its heads, and exports the scale and validation helpers.

Rules:
1. 1. Add ARROWHEAD_SIZE_SCALE and DEFAULT_ARROWHEAD_SIZE to the existing @excalidraw/common import, and ArrowheadSize to the existing `import type { ... } from "./types"`.
2. 2. isArrowheadSize(value) returns `typeof value === "string" && Object.prototype.hasOwnProperty.call(ARROWHEAD_SIZE_SCALE, value)`; it is the only validity test for the field anywhere.
3. 3. getArrowheadSizeScale(element) returns ARROWHEAD_SIZE_SCALE[DEFAULT_ARROWHEAD_SIZE] when element.arrowheadSize is undefined, ARROWHEAD_SIZE_SCALE[element.arrowheadSize] when isArrowheadSize accepts it, and ARROWHEAD_SIZE_SCALE[DEFAULT_ARROWHEAD_SIZE] otherwise; it allocates nothing.
4. 4. Both helpers sit right after getArrowheadSize with a JSDoc line each; getArrowheadSize keeps its signature and values.
5. 5. getArrowheadSizeBeyondLastSegment, cardinality branch: the non-curved result is getArrowheadSize(arrowhead) * Math.min(getArrowheadSizeScale(element), getCardinalityMarkerScale(marker, corner, element.strokeWidth)), so a small marker grows at most to its own size and a large one never past what fits.
6. 6. getArrowheadSizeBeyondLastSegment, case "arrow": `const scale = getArrowheadSizeScale(element);` then legibleSize = (getArrowheadSize(arrowhead) * scale) / 2, and the first getSidesClearSize call takes getArrowheadAngle(arrowhead, legibleSize / scale); the call with angle at size 0 is unchanged.
7. 7. getArrowheadPoints: `const scale = getArrowheadSizeScale(element);` and `const size = getArrowheadSize(arrowhead) * scale;` replace the unscaled size; the fitting below (lengthMultiplier, minSize, getArrowheadSizeBeyondLastSegment) is untouched and so still caps the scaled head on short segments.
8. 8. getArrowheadPoints computes `const angle = getArrowheadAngle(arrowhead, minSize / scale);` so a scaled head keeps the opening angle of the default head at the same relative size.
9. 9. With arrowheadSize absent or "medium" the scale is exactly 1 and every computed value is identical to today.
10. 10. getLinearElementRotatedBounds, right before its final `return coords;` (after the bound-text block, which keeps today's input): when isArrowElement(element) && (element.startArrowhead || element.endArrowhead) && getArrowheadSizeScale(element) > 1, get `const shapes = ShapeCache.generateElementShape(element, null);` and, in a for loop from index 1 (no slice), widen coords with `getMinMaxXYFromCurvePathOps(getCurvePathOps(shapes[i]), transformXY)` (min of the minimums, max of the maximums).
11. 11. Rule 10 gets a short comment: heads above the default size overrun the shaft-only bounds and the export padding, so they join the bounds; default and smaller heads keep today's bounds. Absent, medium and small arrows never enter the branch, so their bounds, export frames and snapshots stay byte-identical.
