### U03 — edit `packages/element/src/bounds.ts` (codegen)

Behaviour: Scale every arrowhead size computation by the element's preset, and widen linear-element bounds by the drawn heads only when the scale is above 1.

Rules:
1. 1. getArrowheadSize(arrowhead, scale = 1) keeps its switch of base sizes and returns base * scale; with no scale it returns HEAD's value.
2. 2. getArrowheadAngle(arrowhead, size?, scale = 1): drawn size = size ?? getArrowheadSize(arrowhead, scale); for `arrow`, fullSize = getArrowheadSize(arrowhead, scale) and the widest size is ARROW_ARROWHEAD_WIDEST_SIZE * scale, so the 20-to-30 degree widening keeps its proportions; every other branch is unchanged.
3. 3. getCardinalityMarkerScale gains a 4th parameter `scale: number` and passes it to each of its three getArrowheadSize calls.
4. 4. getArrowheadSizeBeyondLastSegment computes `const scale = getArrowheadSizeScale(element.arrowheadSize);` first and uses it in the cardinality branch (size and marker scale), the `arrow` legibleSize and both `arrow` getArrowheadAngle calls; the other branches (bar, diamond, triangle, circle) are size-independent caps and stay as they are.
5. 5. getArrowheadPoints computes the same scale and uses getArrowheadSize(arrowhead, scale) as `size` and getArrowheadAngle(arrowhead, minSize, scale) as `angle`; the short-segment clamp code is unchanged, so it clamps the scaled size.
6. 6. New private helper (above getLinearElementRotatedBounds) extends a Bounds by the drawn heads: it walks start then end with the defaults shape.ts uses (`startArrowhead = null`, `endArrowhead = "arrow"` for a legacy undefined), skips a null head, and collects the parts shape.ts draws: cardinality_one_or_many = cardinality_many + cardinality_one at CARDINALITY_ONE_OR_MANY_BAR_OFFSET; cardinality_exactly_one = cardinality_one at CARDINALITY_INNER_BAR_OFFSET + cardinality_one; cardinality_zero_or_one = circle_outline at CARDINALITY_ZERO_CIRCLE_OFFSET with diameter scale CARDINALITY_ZERO_CIRCLE_SCALE + cardinality_one at CARDINALITY_INNER_BAR_OFFSET; cardinality_zero_or_many = cardinality_many + that circle_outline part; any other head is one part of its own type.
7. 7. For each part it calls getArrowheadPoints(element, [shape], position, part, offset); a null result adds nothing; a circle result [x, y, diameter] adds the transformed center plus and minus diameter * diameterScale / 2 on both axes; a cardinality_one result adds only its bar ends (indices 2..5, the pairs generateArrowheadCardinalityOne draws); any other result adds every (x, y) pair. Points go through the same transformXY as the shaft ops before min/max.
8. 8. getLinearElementRotatedBounds calls the helper right after `let coords` is set, only when isArrowElement(element) && getArrowheadSizeScale(element.arrowheadSize) > 1, and before the bound-text merge; lines (which never draw heads) and small/medium/absent sizes skip it, so their bounds and every hit result equal HEAD.
9. 9. No other function changes; ElementBounds caches by version, so the head extent is computed once per element version (no per-hit-test allocation).
