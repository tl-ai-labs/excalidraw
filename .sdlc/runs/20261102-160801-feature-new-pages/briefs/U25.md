### U24 — create `packages/excalidraw/components/PageTabs.tsx` (codegen)

Behaviour: The tab bar: lists live pages, switches on click, and in edit mode creates, renames, reorders and deletes.

Rules:
1. The file imports "./PageTabs.scss". Props are { app: AppClassProperties; appState: UIAppState }. Pages come from getLivePages(appState.pages). All changes go through app.pages. Editing controls (add button, menu buttons, rename, drag) render only when !appState.viewModeEnabled (FR-12).
2. Markup: root div class `page-tabs`, data-testid `page-tabs`, data-viewport-ui `bottom`. Inside, a div role=tablist with aria-label t("pages.tabList"), class `page-tabs__list`, which scrolls when tabs overflow (FR-6). Each page is a div role=presentation class `page-tabs__tab` (with `page-tabs__tab--active`) holding a button role=tab, aria-selected, tabIndex 0 on the active tab and -1 otherwise, title the page name, data-testid `page-tab-${id}`, and in edit mode a button aria-label t("pages.options"), aria-haspopup menu, data-testid `page-tab-menu-${id}`, tabIndex 0 on the active tab and -1 otherwise. After the list, the add button with aria-label t("pages.add"), data-testid `page-tab-add`, PlusIcon.
3. A tab's click calls app.pages.setActivePage(id), then app.focusContainer() when event.detail > 0, so a pointer click gives the keyboard back to the canvas but keyboard activation keeps focus on the tab.
4. A useEffect on activePageId calls `scrollIntoView?.({ block: "nearest", inline: "nearest" })` on the active tab; the optional call is for jsdom.
5. Keyboard on a tab: ArrowRight and ArrowLeft move focus to the next and previous tab, wrapping; Home and End to the first and last; F2 starts rename in edit mode. Handled keys call preventDefault and stopPropagation so canvas shortcuts don't fire (NFR-5). Enter and Space are the button's own click.
6. Rename: double-click or the menu's rename replaces the tab button with an input, aria-label t("pages.renameLabel"), data-testid `page-tab-rename-input`, autofocused and selected, maxLength MAX_PAGE_NAME_LENGTH. Enter or blur commits with app.pages.renamePage. Escape cancels: a ref marks it so the blur that follows doesn't commit. Keys in the input stop propagation. After either, focus returns to the tab (FR-8).
7. Reorder: in edit mode the tab div is draggable. onDragStart stores the id in a ref and calls `event.dataTransfer?.setData("text/plain", id)`; onDragOver calls preventDefault; onDrop calls app.pages.movePage(draggedId, position of the target tab) and stopPropagation (FR-9). Drag state lives in the ref, not dataTransfer, so jsdom's fireEvent works without one.
8. Menu: one menu at a time, in state as the page id. A div role=menu class `page-tabs__menu`, rendered as a child of the root with `left` from the trigger's offset, opening above the bar. Items are buttons role=menuitem with data-testids `page-menu-rename`, `page-menu-move-left`, `page-menu-move-right`, `page-menu-delete`, labelled with t("pages.rename"), t("pages.moveLeft"), t("pages.moveRight"), t("pages.delete"). Move left is disabled at position 0, move right at the last position, delete when one page remains. The first item takes focus on open. useOutsideClick and Escape close it and return focus to the trigger.
9. Delete: when app.scene.getPageElements(id) has a non-deleted element, open ConfirmDialog with title t("pages.deleteConfirmTitle") and body t("pages.deleteConfirm", { name }), and call app.pages.deletePage on confirm. An empty page deletes at once (FR-10).
10. Add calls app.pages.createPage().
