### U03 — create `packages/element/src/pages.ts` (codegen)

Behaviour: The page model as pure functions: element membership, the page list and its edits, reconciliation, and the helpers save and export use.

Rules:
1. No App, React or AppState import. Functions taking appState declare the structural fields they read. Depends only on @excalidraw/common, @excalidraw/fractional-indexing, ./mutateElement and ./types.
2. Order: a private comparator sorts by index, then id. getLivePages filters `isDeleted` and sorts; it returns a new array.
3. getElementPageId returns `element.pageId ?? DEFAULT_PAGE_ID`.
4. adoptElementsIntoPage mutates in place and returns the same array. For each element whose getElementPageId differs from pageId, or whose pageId equals DEFAULT_PAGE_ID: when pageId is DEFAULT_PAGE_ID delete the `pageId` key, otherwise assign it. It does not bump version: the caller owns these elements. Cast through Mutable.
5. groupElementsByPage returns a Map from page id to elements, keeping each group's array order and first-seen key order.
6. hasPagedElements is true when any element has a truthy pageId. It is the fast-path test for restore and reconcile.
7. getDefaultPage returns a new record {id: DEFAULT_PAGE_ID, name: `${PAGE_NAME_PREFIX} 1`, index "a0", version 1, versionNonce 0, isDeleted false, updated 0}. It uses no random or clock value, so it is identical across clients and snapshots.
8. getNextPageName looks at live names only and matches them against /^Page (\d+)$/ built from PAGE_NAME_PREFIX. N is one more than the highest match, or 1 when none matches (FR-5).
9. normalizePageName trims, slices to MAX_PAGE_NAME_LENGTH, and returns `fallback` when the result is empty (FR-5). Duplicate names are allowed.
10. A private bumpPage returns `{...page, ...updates, version: page.version + 1, versionNonce: randomInteger(), updated: getUpdatedTimestamp()}`.
11. newPage returns a record with id randomId(), the normalized name (fallback getNextPageName(pages)), index `generateNKeysBetween(last live index or null, null, 1)[0]`, version 1, versionNonce randomInteger(), isDeleted false, updated getUpdatedTimestamp(). It does not add the record to the list.
12. renamePage bumps the record when the normalized name differs and returns `pages` unchanged otherwise. An empty name keeps the previous name (FR-5).
13. movePage: `toPosition` is the target position in the live order, clamped to the range. Take the live list without the page, and generate an index between the neighbours at toPosition. When the neighbours have equal indices, reassign every live page's index with generateNKeysBetween(null, null, n) in the target order and bump each record whose index changed. Return `pages` unchanged when the position does not change.
14. deletePage bumps the record with isDeleted true. It does not check the last-page rule: that belongs to the caller.
15. getNeighbourPageId takes the live pages in order, a page id, and an optional set of ids still live. It returns the next page in order, else the previous one, skipping ids outside the set, or null when none exists (FR-10, FR-27).
16. getPagesVersion sums `version` over all records including tombstones.
17. reconcilePages merges by id. When only one side has the pristine default record (id DEFAULT_PAGE_ID, version 1) and the other side is non-empty, drop it. For an id on both sides: if either is deleted the result is the deleted record with the higher version; otherwise higher version wins, then lower versionNonce, keeping local on a tie. Sort the result. When no live record remains, revive the lowest record with `{...record, isDeleted: false}` and no bump, so all clients revive the same one. Return the `localPages` reference when nothing differs from it.
18. applyPageTombstones: with no tombstones return `elements` unchanged. Otherwise map elements, replacing each non-deleted element whose getElementPageId is a tombstoned id with newElementWith(element, { isDeleted: true }); return the input reference when none changed.
19. getActivePageElements returns `elements` unchanged when `appState?.activePageId` is undefined or no element has a pageId and the id is DEFAULT_PAGE_ID; otherwise it filters by getElementPageId.
20. scopeAppStateToActivePage returns appState unchanged when it has no `pages`; otherwise a copy where `pages` holds only the active record, or the first live record when no record matches, and `pageViewports` comes from getPageViewportsForSave and holds only that page's entry.
21. getPageViewportsForSave returns `pageViewports` with the active page's entry set to {scrollX, scrollY, zoom: zoom.value} when those fields are present; it returns `pageViewports ?? {}` otherwise.
22. isValidPageIndex is true for a non-empty string that validateOrderKey accepts, with the throw caught. assignPageIndices returns copies with indices from generateNKeysBetween(null, null, pages.length) in the given order, with no bump; movePage's reindex uses it.
