Behaviour: Collaboration syncs every page and the page list: it reconciles pages with elements on every receive, applies delete-wins, and relays the active page to cursors and followers.

Rules:
1. _reconcilePages(remotePages) calls reconcilePages(this.excalidrawAPI.getAppState().pages, remotePages ?? []), stores getPagesVersion of the result in lastBroadcastedOrReceivedPagesVersion, and returns it. A missing remotePages comes from an older client or a legacy room.

Otherwise it broadcasts lastPointerPayload through portal.broadcastMouseLocation when set, and calls relayVisibleSceneBounds(), so remote cursors and followers update without a pointer move (FR-26).
5. broadcastElements(elements, pages) broadcasts when getSceneVersion(elements) is above the last version, or getPagesVersion(pages) is above lastBroadcastedOrReceivedPagesVersion, and stores both.
6. getSceneElementsIncludingDeleted on this class returns getAllPagesElementsIncludingDeleted(), so every internal reader and Portal's new-user handler see the whole drawing.

### U29 — edit `excalidraw-app/data/firebase.ts` (codegen)

Behaviour: Persists the page list next to the elements, encrypted with the room key, without changing what `ciphertext` holds.

Rules:
1. encryptPages encrypts JSON.stringify(pages) with encryptData, as encryptElements does. decryptPages returns [] when pagesIv or pagesCiphertext is missing, which is a legacy or older-client document; otherwise it decrypts, JSON.parses and returns the records.
2. FirebaseSceneVersionCache stores `getSceneVersion(elements) + getPagesVersion(pages)`, so a page-only change is unsaved. `sceneVersion` in the document stays elements only.
3. saveToFirebase keeps its signature and reads `appState.pages`. It bails on isSavedToFirebase(portal, elements, pages). With no document it creates one with getSyncablePages(pages).
4. With a document it decrypts stored pages and elements, computes `reconciledPages` with getSyncablePages(reconcilePages(pages, storedPages)), and `reconciledElements` with getSyncableElements(applyPageTombstones(reconcileElements(...as today), reconciledPages)), so delete wins in storage too (FR-27). `transaction.update` writes all five fields.
5. After the transaction it decrypts the stored scene as today, sets the cache, and returns `{ elements: toBrandedType<RemoteExcalidrawElement[]>(storedElements), pages: storedPages }`, or null where it returns null today.
6. loadFromFirebase returns `{ elements, pages }` or null where it returns null today. Pages are decrypted raw and not repaired: an empty list means a legacy room, and callers reconcile it with local pages.

Exports:
- `isSavedToFirebase(portal: Portal, elements: readonly ExcalidrawElement[], pages: readonly ExcalidrawPage[]): boolean`
- `saveToFirebase(portal: Portal, elements: readonly SyncableExcalidrawElement[], appState: AppState): Promise<{ elements: RemoteExcalidrawElement[]; pages: readonly ExcalidrawPage[] } | null>`
- `loadFromFirebase(roomId: string, roomKey: string, socket: Socket | null): Promise<{ elements: readonly SyncableExcalidrawElement[]; pages: readonly ExcalidrawPage[] } | null>`
