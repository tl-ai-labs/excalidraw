### U11 — edit `packages/excalidraw/data/restore.ts` (codegen)

Behaviour: Restore repairs page data: legacy and malformed input become one default page, elements are restored page by page, and appState's page keys are restored from the supplied data only.

Rules:
1. restorePages: a non-array or empty input returns [getDefaultPage()]. Otherwise walk the entries: skip anything that is not an object with a non-empty string `id`, and skip an id already seen (first wins). name is normalizePageName of a string name with fallback getNextPageName(accepted so far). version is a finite number >= 1, else 1. versionNonce and updated are finite numbers, else 0. isDeleted is `!!isDeleted`. Keep tombstones.
2. restorePages ordering: when every accepted index passes isValidPageIndex and no two are equal, sort live and tombstones together by index then id. Otherwise run assignPageIndices over the accepted records in input order. When no live record remains, return [getDefaultPage()].
3. restoreActivePageId returns the supplied id when it names a live page, otherwise the first live page's id (FR-21).
4. restorePageViewports keeps entries whose key names a page in `pages` and whose scrollX, scrollY and zoom are finite, with zoom passed through getNormalizedZoom. Anything else is dropped; a non-object input returns {}.
5. restoreElementPages returns the input reference when every element's getElementPageId is a page in `pages`, tombstones included. Otherwise it maps: an element on an unknown page, or with no pageId when the default page isn't in the list, becomes a copy on the first live page; a move to DEFAULT_PAGE_ID removes the key. No version bump, like other restore normalization.
6. restoreElements: run restoreElementPages first when opts.pages is set, so moved elements join the first page's group in array order. When no element has a pageId, call restorePageElements once, so a one-page drawing takes exactly today's path. Otherwise flatMap restorePageElements over groupElementsByPage's groups. One `existingIds` Set is shared across groups, so a duplicate id across pages still gets a new id. Bindings and frames are repaired against one group, which enforces FR-15.

### U17 — create `packages/excalidraw/components/App.pages.ts` (codegen)

Behaviour: AppPages owns every change to the page list and the active page: it switches pages, applies remote lists, routes host writes, and replaces the drawing on load.

Rules:
1. setActivePage(pageId): return when pageId is the active page or isn't live. No view-mode check here: the role matrix lets view-mode users switch and lets hosts do everything.
2. setActivePage step 1: call `app.text.textWysiwygSubmitHandler?.()`. Then in flushSync, when state.multiElement or state.selectedLinearElement?.isEditing is set, run `app.actionManager.executeAction(actionFinalize)`, and call `app.setState({})`, so componentDidUpdate commits the Store and the work lands on the leaving page's undo stack (FR-11, FR-17).
3. setActivePage step 2: call `app.viewport.destroy()`, which only cancels viewport animations and snap-back, so an animation can't move the new page.
4. setActivePage step 3: read app.state fresh. Build nextState: activePageId; pageViewports with the leaving page's entry set to its {scrollX, scrollY, zoom: zoom.value}; scrollX, scrollY and zoom from the target's entry, or 0, 0 and 1 for a page with none (FR-13); selectedElementIds {}, previousSelectedElementIds {}, selectedGroupIds {}, hoveredElementIds {}, editingGroupId null, selectedLinearElement null, editingTextElement null, newElement null, multiElement null, resizingElement null, selectionElement null, activeEmbeddable null, activeLockedId null, editingFrame null, isCropping false, croppingElementId null, contextMenu null, showHyperlinkPopup false, suggestedBinding null, frameToHighlight null, elementsToHighlight null, snapLines [].
5. setActivePage step 4: `history.setActivePage(pageId)`. Then in flushSync: `app.scene.setActivePage(pageId)`, `app.store.resetSnapshot(app.scene.getElementsMapIncludingDeleted(), { ...state, ...nextState })`, and `app.setState(nextState)`. Scene and state change in one commit, and nothing is captured, so a switch is not an undo step (FR-17).
6. setActivePage step 5: call addNewImagesToImageCache() and `app.fonts.loadSceneFonts(state.currentItemFontFamily).then((fontFaces) => app.fonts.onLoaded(fontFaces))`, because both only walk the active page.
7. createPage({ name, activate = true } = {}): build with newPage, commit `pages: [...state.pages, page]` in flushSync, call setActivePage when activate, and return the record.
8. renamePage and movePage call the pure functions and commit in flushSync when the list reference changed.
9. deletePage returns false when the page isn't live or is the last live page (FR-10). When it is the active page, setActivePage(getNeighbourPageId(live, pageId)) first. Then map app.scene.getPageElements(pageId) with newElementWith(element, { isDeleted: true }) for non-deleted elements, and write with `app.scene.replaceElementsByPage(new Map([[pageId, elements]]))`. Call history.deletePage(pageId). Commit the list from the pure deletePage and pageViewports without that key in flushSync. Return true.
10. applyPages(pages): return when `pages === state.pages`. Compute the ids live in `pages`. Call history.deletePage for each previously live id no longer live. Commit `pages` and pageViewports pruned to live ids in flushSync. When the active page is no longer live, setActivePage(getNeighbourPageId(prevLive, activePageId, nextIds) ?? first live id) (FR-27).
11. routeElements(elements, wholeDrawing): when not wholeDrawing and one live page and `!app.scene.hasOtherPages()`, return null, which is the constant-time path to replaceAllElements. When wholeDrawing, return groupElementsByPage(elements) with an empty group added for the active page if it has none. Otherwise, for each element: a pageId naming a live page goes there; else an id found in arrayToMap(app.scene.getAllElementsIncludingDeleted()) goes to that element's page; else the active page (FR-16). When elements is empty, return a Map with an empty group for the active page.
12. isUndoableReplace(pages): true when the scene has no other pages, the current live list is one page with DEFAULT_PAGE_ID, and getLivePages(pages) is one page with DEFAULT_PAGE_ID.
13. replaceDrawing(elements, appState): when isUndoableReplace(appState.pages), call app.scene.replaceAllElements(elements) and return. Otherwise call history.clear() and history.setActivePage(appState.activePageId), then app.scene.replaceElementsByPage(groupElementsByPage(elements), { replaceAll: true, activePageId: appState.activePageId }), then app.store.resetSnapshot(app.scene.getElementsMapIncludingDeleted(), { ...app.state, ...appState }).
14. omitPageState returns a copy of appState without pages, activePageId and pageViewports, and returns null for null.
