### U28 — edit `excalidraw-app/data/firebase.ts` (codegen)

Behaviour: The Firestore scene keeps the encrypted bare element array in ciphertext/iv for old clients and stores the page list in its own encrypted pagesCiphertext/pagesIv fields; a document without them reads as the default page.

Rules:
1. 1. FirebaseStoredScene gains optional `pagesCiphertext?: Bytes` and `pagesIv?: Bytes`; sceneVersion, iv and ciphertext keep their names and types.
2. 2. encryptElements and decryptElements stay exactly as today: ciphertext is UTF-8 JSON.stringify of the bare element array.
3. 3. New private encryptPages(key, pages): encryptData(key, UTF-8 JSON.stringify(pages)) returning { ciphertext, iv } like encryptElements; new private decryptPages(data, roomKey): return createDefaultPages() when data.pagesCiphertext or data.pagesIv is missing, else decryptData(pagesIv, pagesCiphertext, roomKey), JSON.parse and restorePages(parsed).
4. 4. One version value = getSceneVersion(elements) + getPagesVersion(pages); FirebaseSceneVersionCache.set(socket, elements, pages) stores it, isSavedToFirebase compares it, createFirebaseSceneDocument writes it to sceneVersion.
5. 5. createFirebaseSceneDocument(elements, pages, roomKey) returns { sceneVersion, ciphertext, iv, pagesCiphertext, pagesIv } (all Bytes.fromUint8Array as today).
6. 6. isSavedToFirebase(portal, elements, pages); saveToFirebase(portal, elements, appState) bails on isSavedToFirebase(portal, elements, appState.pages); a new document is written with transaction.set(docRef, doc) holding all five fields; an existing one reconciles elements as today, reconciles pages = reconcilePages(appState.pages, await decryptPages(prevStoredScene, roomKey)) and writes all five fields with transaction.update(docRef, doc).
7. 7. After the transaction saveToFirebase decrypts the stored document's elements (as today) and pages (decryptPages), sets the version cache from both, and returns { elements, pages }; it returns null where it returns null today.
8. 8. loadFromFirebase returns { elements, pages } | null: elements as today, pages = decryptPages(storedScene, roomKey); it sets the version cache from both.
9. 9. Page names never leave the encrypted pages payload and are never logged.
