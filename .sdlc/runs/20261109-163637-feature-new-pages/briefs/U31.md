### U03 — create `packages/element/src/pages.ts` (codegen)

Behaviour: Pure page-model helpers: defaults, ordering, home/active page resolution, element membership, stamping, per-page versioned merge, restore sanitizing.

Rules:
1. 1. Imports: DEFAULT_PAGE_ID, randomId, randomInteger from @excalidraw/common; generateKeyBetween from @excalidraw/fractional-indexing; types ExcalidrawElement, ExcalidrawPage, FractionalIndex from ./types. No React, no DOM.
2. 2. sortPages returns a new array sorted by index ascending, ties by id ascending (string compare) so every peer orders identically.
3. 3. createDefaultPages returns a fresh [{ id: DEFAULT_PAGE_ID, name: "", index: "a0", version: 1, versionNonce: 0, isDeleted: false }] each call.
4. 4. getHomePageId: DEFAULT_PAGE_ID if any page (deleted or not) has that id, else the smallest id (string compare) among all pages incl. tombstones, else DEFAULT_PAGE_ID. It never depends on page order, so reorder and delete never move the home page.
5. 5. resolveActivePageId: the given id when it names a non-deleted page; else the home page id when that page is non-deleted; else the first non-deleted page id; else DEFAULT_PAGE_ID.
6. 6. getScenePageOptions(pages, activePageId) is memoized on the identity of both arguments (keep the last args and result in module-level variables) and returns { activePageId: resolveActivePageId(...), homePageId: getHomePageId(pages), pageIds: Set of every page id incl. tombstones, isSinglePage: pages.length <= 1 }.
7. 7. getElementPageId(element, options): when options is null return DEFAULT_PAGE_ID; return element.pageId when it is a string present in options.pageIds, otherwise options.homePageId.
8. 8. isElementOnActivePage(element, options): true when options is null or options.isSinglePage, else getElementPageId(element, options) === options.activePageId.
9. 9. stampElementsPage mutates the given fresh elements in place (cast to Mutable): when options is null do nothing; when options.activePageId === options.homePageId delete element.pageId; otherwise set element.pageId = options.activePageId. It never changes version.
10. 10. generatePageIndex(pages) = generateKeyBetween(highest index over all pages incl. tombstones or null, null) cast to FractionalIndex.
11. 11. getReorderedPageIndex(pages, pageId, toPosition): take the sorted non-deleted pages without pageId, clamp toPosition to [0, length], return generateKeyBetween(prev?.index ?? null, next?.index ?? null) where prev = list[toPosition - 1] and next = list[toPosition]; when prev and next share the same index (tie) use generateKeyBetween(prev.index, null) only if next is undefined, else return prev.index (ties sort by id).
12. 12. newPage({ name, pages }) returns { id: randomId(), name, index: generatePageIndex(pages), version: 1, versionNonce: randomInteger(), isDeleted: false }.
13. 13. updatePage(page, updates) returns a new page with the updates, version + 1 and a new randomInteger() versionNonce.
14. 14. reconcilePages(local, remote): per id keep local when local.version > remote.version or (equal versions and local.versionNonce <= remote.versionNonce), else remote; include ids present on only one side; return sortPages(result). Same rule as shouldDiscardRemoteElement in data/reconcile.ts.
15. 15. getPagesVersion(pages) = sum of page.version (0 for an empty or missing list).
16. 16. applyPageChanges(pages, changed): for each changed page, if an existing page has its id replace it with { ...existing, name, index, isDeleted taken from changed, version: max(existing.version, changed.version) + 1, versionNonce: randomInteger() }, else append { ...changed, version: changed.version + 1, versionNonce: randomInteger() }; return sortPages(result).
17. 17. restorePages(input: unknown): keep only objects with a non-empty string id (first occurrence wins), a string name (else ""), a string index (else generate one after the previous kept page), finite version >= 1 (else 1), finite versionNonce (else 0), boolean isDeleted (else false); sort; if no non-deleted page remains return createDefaultPages() plus the kept tombstones. Never throws.
