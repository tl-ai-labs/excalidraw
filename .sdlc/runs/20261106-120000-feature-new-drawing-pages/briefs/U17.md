### U17 — create `packages/excalidraw/components/PageTabs.tsx` (codegen)

Behaviour: Render the page tab bar allowing users to switch pages, add a page, rename a page inline, reorder pages, and delete a page with confirmation.

Rules:
1. 1. Export const PageTabs = ({ appState }: { appState: UIAppState }) => JSX.Element reading app via useApp() and translations via t() from ../i18n.
2. 2. Render a container with role="tablist" and aria-label={t("pages.tabsLabel")} containing a tab for each page in appState.pages with role="tab", aria-selected={page.id === appState.activePageId}, data-testid={`page-tab-${page.id}`}, and draggable={!appState.viewModeEnabled && editingPageId !== page.id}.
3. 3. Clicking a tab calls app.switchPage(page.id); double-clicking a tab (or clicking its rename button with data-testid={`page-rename-${page.id}`} and aria-label={t("pages.renamePage")}) when !appState.viewModeEnabled opens an inline input (data-testid={`page-rename-input-${page.id}`}) initialized to page.name that commits via app.renamePage(page.id, draftName) on Enter or blur and cancels on Escape (stopping key event propagation so canvas shortcuts do not fire while typing).
4. 4. Support reordering pages when !appState.viewModeEnabled both via HTML5 drag-and-drop (onDragStart, onDragOver, onDrop calling app.reorderPages(fromIndex, toIndex)) and via move-left / move-right buttons (data-testid={`page-move-left-${page.id}`} and data-testid={`page-move-right-${page.id}`}, disabled at boundaries).
5. 5. When !appState.viewModeEnabled, render an Add Page button (data-testid="page-add-button", aria-label={t("pages.addPage")}) that calls app.addPage(), and a Delete Page button per tab (data-testid={`page-delete-${page.id}`}, aria-label={t("pages.deletePage")}, disabled when appState.pages.length <= 1) that opens ConfirmDialog (titled t("pages.deletePageConfirmTitle") with body t("pages.deletePageConfirmDescription", { pageName: page.name })) and calls app.deletePage(page.id) on confirm.
6. 6. When appState.viewModeEnabled is true, allow clicking tabs to switch pages while hiding or disabling add, rename, reorder, and delete controls.
