### U19 — create `packages/excalidraw/actions/actionPages.ts` (codegen)

Behaviour: The page actions: add, switch, rename, move left/right, move to index, delete.

Rules:
1. Each action is register({...}) with trackEvent { category: "canvas" } and returns captureUpdate CaptureUpdateAction.NEVER (page structure is not undoable; switching never is).
2. A shared getPageSwitchAppState(appState, targetPageId) returns the partial AppState for a switch: pageViewports with the live {scrollX, scrollY, zoom: zoom.value} stored under appState.activePageId; activePageId target; scrollX/scrollY/zoom from pageViewports[target] (zoom via getNormalizedZoom) or 0/0/1; cleared selectedElementIds {}, selectedGroupIds {}, editingGroupId null, previousSelectedElementIds {}, hoveredElementIds {}, selectedLinearElement null, editingTextElement null, newElement null, multiElement null, resizingElement null, isCropping false, croppingElementId null, suggestedBinding null, frameToHighlight null, elementsToHighlight null, activeEmbeddable null, editingFrame null, snapLines [], searchMatches unchanged, contextMenu null. Returns null when target equals the active page or is not a visible page.
3. actionSwitchPage (name switchPage, viewMode true, label pages.switchPage): value is the target page id; returns false when getPageSwitchAppState is null.
4. actionAddPage (name addPage, viewMode false, label pages.addPage, icon PlusIcon): createPage(appState.pages, appState.activePageId); then switch to it via getPageSwitchAppState over the appState with the new pages.
5. actionRenamePage (name renamePage, viewMode false, label pages.renamePage): value { pageId: string; name: string }; renamePage(...); returns false when the array is unchanged (empty or same name).
6. actionMovePage (name movePage, viewMode false, label pages.movePage): value { pageId: string; toIndex: number }; movePage(...); false when unchanged.
7. actionMovePageLeft / actionMovePageRight (names movePageLeft/movePageRight, labels pages.movePageLeft/movePageRight): value is a page id or null (null = active page); move to its visible position - 1 / + 1; predicate false when already first / last; false when unchanged.
8. actionDeletePage (name deletePage, viewMode false, label pages.deletePage, icon TrashIcon): value page id or null (active); predicate false when only one visible page; computes adjacent = getAdjacentPageId before deleting; elements returned = elements.map(el => isElementOnPage(el, pageId) && !el.isDeleted ? newElementWith(el, { isDeleted: true }) : el); pages = deletePage(...); when the deleted page is active, also applies getPageSwitchAppState toward adjacent (computed on the pre-delete pages) and drops pageViewports[pageId]; returns false when deletePage leaves pages unchanged.
9. Every action's perform returns false when the editor is in view mode and the action is not viewMode (rely on the manager) and never touches other pages' elements.
