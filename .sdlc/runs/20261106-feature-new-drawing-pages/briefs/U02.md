### U02 — create `packages/element/src/pages.ts` (codegen)

Behaviour: Pure page helpers: default page, visible ordering, create/rename/reorder/delete records, page membership of elements, page reconciliation and versioning.

Rules:
1. DEFAULT_PAGE_ID = "default"; getDefaultPages() returns [{ id: DEFAULT_PAGE_ID, name: "Page 1", index: "a0", version: 1, versionNonce: 0, isDeleted: false }].
2. getElementPageId(element) returns element.pageId ?? DEFAULT_PAGE_ID; isElementOnPage(element, pageId) compares that.
3. getVisiblePages(pages): non-deleted pages sorted by index (string compare), ties by id; never mutates the input.
4. getDefaultPageName(pages): "Page N" where N starts at visible count + 1 and increments while a visible page already has that exact name.
5. createPage(pages, afterPageId, name?): new record with id randomId(), name ?? getDefaultPageName(pages), version 1, versionNonce randomInteger(), isDeleted false, index generateKeyBetween(after.index, nextVisible?.index ?? null) from @excalidraw/fractional-indexing (after = the visible page afterPageId, or the last visible page when not found; null bounds when no visible pages); returns { pages: [...pages, page], page }.
6. Every record update goes through a local bumpPage(page, updates) that returns a new object with version + 1 and a new randomInteger() versionNonce.
7. renamePage(pages, pageId, name): trimmed name; returns the same array when the trimmed name is empty, the page is missing/deleted, or the name is unchanged; else the array with that record bumped.
8. movePage(pages, pageId, toIndex): toIndex is a position in getVisiblePages without the moved page, clamped to [0, length]; computes generateKeyBetween(prev?.index ?? null, next?.index ?? null) for the gap and bumps that one record; returns the same array when the position does not change.
9. deletePage(pages, pageId): returns the same array when the page is missing/deleted or it is the only visible page; else that record bumped with isDeleted true.
10. getAdjacentPageId(pages, pageId): id of the next visible page after pageId, else the previous one, else null.
11. getPageElements(elements, pageId): elements on that page, deleted included, in array order.
12. assignElementToPage(element, pageId): mutates the plain object in place (for elements not yet in a scene): deletes the pageId key for DEFAULT_PAGE_ID, else sets it; returns the element.
13. reassignOrphanedElementsToPage(elements, pages): elements whose page is not a visible page get newElementWith(element, { pageId: firstVisible.id === DEFAULT_PAGE_ID ? undefined : firstVisible.id }) plus deleting a leftover pageId key for the default page via a spread copy; returns the same array when nothing changes.
14. reconcilePages(local, remote): union by id; for an id in both keep the record with the higher version, ties to the lower versionNonce; result is ordered by index then id; returns local unchanged when remote is null/undefined or empty.
15. getPagesVersion(pages): sum of versions (0 for undefined).
16. restorePageState(appState): validates untrusted input. pages: keep entries that are objects with a non-empty string id and string name, unique by id (first wins), fill index (generateNKeysBetween for missing/invalid keys in array order, using validateOrderKey in try/catch), version (finite >= 1 else 1), versionNonce (finite else 0), isDeleted (boolean else false); when no visible page remains return getDefaultPages(). activePageId: the given id when it is a visible page, else the first visible page id. pageViewports: keep entries whose key is a known page id and whose scrollX/scrollY/zoom are finite numbers (zoom > 0); else {}.
17. toActivePageExportState(appState): returns { ...appState, pages: only the active page record (or getDefaultPages() when missing), pageViewports: only the active page entry when present }; leaves other keys as they are.
