### U08 — edit `packages/excalidraw/actions/colorTargets.ts` (codegen)

Behaviour: Adds the per-app text editor selection registry, and applyTextRangeColor, which turns a colour pick into a styleRanges update on the edited text when a non-empty editor selection is active.

Rules:
1. 1. A module-level `const textEditorSelectionGetters = new WeakMap<object, () => TextEditorSelection | null>()`.
2. 2. registerTextEditorSelectionGetter sets the getter for app and returns an unregister function. The unregister deletes the entry only if the stored getter is still the one it registered.
3. 3. getTextEditorSelection returns null for a missing app or getter. Otherwise it returns the getter's result with start <= end.
4. 4. applyTextRangeColor returns null (the caller falls back to today's behaviour) when appState.editingTextElement is null, when the selection is null or collapsed (start >= end), when no non-deleted text element with the editing id is in elements, or when the selection covers the whole text (start <= 0 and end >= target.originalText.length).
5. 5. Otherwise it computes nextRanges = applyStyleToRange(target.styleRanges, start, end, { [property]: color }, target.originalText.length, target.strokeColor).
6. 6. If areStyleRangesEqual(target.styleRanges, nextRanges), it returns elements unchanged. Otherwise it returns elements mapped with the target replaced by newElementWith(target, { styleRanges: nextRanges }, true). Every other element and the target's own strokeColor and backgroundColor are left untouched.

- `type TextEditorSelection(): { start: number; end: number }`
- `function registerTextEditorSelectionGetter(app: object, getter: () => TextEditorSelection | null): () => void`
- `function getTextEditorSelection(app: object | null | undefined): TextEditorSelection | null`
- `function applyTextRangeColor(elements: readonly T[] (T extends ExcalidrawElement), appState: Pick<AppState, "editingTextElement">, app: object | null | undefined, property: ColorProperty, color: string): readonly T[] | null`
