### U02 — create `packages/element/src/textStyleRanges.ts` (codegen)

Behaviour: Pure range model with no DOM or canvas: normalise, sanitise, compare, apply a style to a range, shift on text edits, and map ranges onto wrapped lines.

Rules:
1. 1. Imports: isTransparent from @excalidraw/common, and `import type { TextStyleRange } from "./types"`. Nothing else: no DOM, canvas or measurement.
2. 2. Export `type TextStyleRun = { text: string; strokeColor?: string; backgroundColor?: string }`.
3. 3. normalizeStyleRanges: return undefined when ranges is not a non-empty array. Clamp start and end into [0, textLength]. Drop entries with start >= end or with no non-empty string colour. Resolve overlaps per property, later entries in array order winning: split at every boundary, and each segment takes, for each property, the value from the last entry that covers it and defines it. Drop segments with no colour. Merge touching segments (end === next start) with equal strokeColor and backgroundColor. Return the result sorted by start, or undefined when it is empty.
4. 4. sanitizeStyleRanges(value: unknown): return undefined when value is not an array. Keep only plain non-null, non-array objects whose start and end pass Number.isInteger and that carry at least one non-empty string strokeColor or backgroundColor. Copy only start, end and the string colour keys. Then return normalizeStyleRanges(kept, textLength).
5. 5. areStyleRangesEqual: undefined, null and [] are all equal. Otherwise both arrays have the same length and every pair has equal start, end, strokeColor and backgroundColor.
6. 6. applyStyleToRange: clamp start and end into [0, textLength]; if start >= end, return normalizeStyleRanges(ranges, textLength). Each key present in style is a property to set or clear. Clear strokeColor when its value is null or equals baseStrokeColor. Clear backgroundColor when its value is null or isTransparent(value). Otherwise set the value. Outside [start, end) existing ranges are unchanged. Inside it, existing ranges are split at start and end; the named properties are set or cleared, and the properties not named keep their values. Uncovered gaps inside the selection gain the set properties. Return the normalised result.
7. 7. shiftStyleRangesForEdit: return ranges unchanged (same reference) when it is undefined or empty, or when prevText === nextText.
8. 8. In shiftStyleRangesForEdit, derive the edit from the texts. prefix = length of the common prefix, capped at min(prev.length, next.length). When caret is a finite number, cap prefix at max(0, caret - max(0, next.length - prev.length)). suffix = length of the common suffix of the parts after prefix, capped at min(prev.length, next.length) - prefix. Then offset = prefix, deleted = prev.length - prefix - suffix, inserted = next.length - prefix - suffix.
9. 9. Map each range through the deletion first: a position p <= offset stays p; p >= offset + deleted becomes p - deleted; anything between becomes offset. Then through the insertion: newStart = s >= offset ? s + inserted : s, and newEnd = e > offset ? e + inserted : e. So text inserted strictly inside a range grows it, and text inserted at a range's start or end is not coloured. Return normalizeStyleRanges(mapped, next.length), which drops ranges that collapse.
10. 10. getStyleRunsForLines: split wrappedText on \n. Keep a cursor into originalText, starting at 0. For a non-empty line, starting at the cursor, skip whitespace and \n characters of originalText until originalText.startsWith(line, pos); test startsWith before skipping each character. The match sets lineStart = pos and moves the cursor to pos + line.length. If no match is found, the line becomes a single unstyled run and the cursor does not move.
11. 11. getStyleRunsForLines output: one array per wrapped line. An empty line gives []. A matched line is split at the range boundaries inside [lineStart, lineStart + line.length) into runs whose text concatenates exactly to the line. A run copies the strokeColor and backgroundColor of the range covering it, and a run outside every range carries no colour keys. When ranges is undefined or empty, every non-empty line is [{ text: line }].
12. 12. No returned object ever holds a key whose value is undefined. Inputs are never mutated.
