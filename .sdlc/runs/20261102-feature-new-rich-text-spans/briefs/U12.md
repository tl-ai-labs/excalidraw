### U05 — edit `packages/element/src/textElement.ts` (codegen)

Behaviour: Adds getTextStyleRunLayout, which positions each style run of each rendered line of a text element (x from the element's left edge, measured width), for canvas and SVG to share.

Rules:
1. 1. Return null when element.styleRanges is undefined or empty, or when isRTL(element.text). This is the only work done for a text without runs (NFR-2).
2. 2. lines = element.text.replace(/\r\n?/g, "\n").split("\n"), the split the renderers use. runsPerLine = getStyleRunsForLines(element.originalText, element.text, element.styleRanges). font = getFontString(element).
3. 3. For each line: lineWidth = getLineWidth(line, font, env). lineStartX is (element.width - lineWidth) / 2 for textAlign center, element.width - lineWidth for right, and 0 otherwise.
4. 4. For each run, with offset = the summed text length of the earlier runs on the line: x = lineStartX + getLineWidth(line.slice(0, offset), font, env), and width = getLineWidth(line.slice(0, offset + run.text.length), font, env) - getLineWidth(line.slice(0, offset), font, env).
5. 5. The result has one array per line (an empty line gives []), and each item is the run spread with x and width.

Exports:
- `type PositionedTextStyleRun(): TextStyleRun & { x: number; width: number }`
- `function getTextStyleRunLayout(element: ExcalidrawTextElement, env: RenderEnvironment | undefined): PositionedTextStyleRun[][] | null`
