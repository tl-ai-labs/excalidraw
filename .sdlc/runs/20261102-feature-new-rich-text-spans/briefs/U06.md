### U03 — create `packages/element/src/textStyleRanges.ts` (codegen)

Behaviour: The styled-range model: pure functions for applying, clearing, remapping, sanitising, merging and laying out ranges on a text element.

Rules:
1. 1. Runtime imports only from @excalidraw/common (randomId, hasRTLChars, getFontString, MAX_CLEARED_TEXT_STYLE_RANGES) and ./textMeasurements (getLineWidth). Types from ./types and ./renderEnvironment. Declare local `const MAX_TEXT_ALIGN_CELLS = 1_000_000;`.
2. 2. Internal resolveState(ranges, cleared) -> TextStyleState is the one canonicaliser: keep one cleared entry per id (highest seq); keep one range per id (highest seq, first on a tie); remove a range whose id has a cleared entry with seq >= the range's; remove a cleared entry whose id has a live range with a higher seq; sort both lists ascending by seq then id using < on the id string; keep only the last MAX_CLEARED_TEXT_STYLE_RANGES cleared entries.
3. 3. Internal colour check: a string of at most 64 characters matching /^#(?:[0-9a-f]{3,4}|[0-9a-f]{6}|[0-9a-f]{8})$/i, or /^[a-z]{3,30}$/i, or /^(?:rgb|hsl)a?\([\d\s.,%/]+\)$/i.
4. 4. Internal sanitizeRange(value: unknown, textLength) -> TextStyleRange | null: value must be a non-null object; id a non-empty string of at most 64 characters; seq a positive safe integer; start and end integers (Number.isInteger). Clamp both into [0, textLength], return null unless start < end. color and highlight, when present (not undefined), must pass rule 3, else null. Require at least one. Return a new object holding only id, seq, start, end and the colours that are set, so unknown keys never pass through.
5. 5. Internal alignText(prev, next, caret?) -> Int32Array of prev.length, each entry the index in next of that code unit, or -1. suffix = common suffix, capped at min(prev.length, next.length) and, when caret is given, at next.length - caret. prefix = common prefix, capped at min(prev.length, next.length) - suffix. Map prefix and suffix one to one. Let m, n be the middle lengths; when m > 0, n > 0 and m * n <= MAX_TEXT_ALIGN_CELLS, build an LCS table in a Uint16Array of (m + 1) * (n + 1), filled from the end. Walk from (0,0): when chars are equal and the cell equals the diagonal + 1 take a match, else advance i if table[i+1][j] >= table[i][j+1], else advance j. Consecutive matches form a block; discard blocks shorter than 2 code units.
6. 6. Internal mapRange(range, map) -> TextStyleRange | null: find the first and last index in [start, end) with map[i] >= 0; none gives null; otherwise return the range with start = map[first] and end = map[last] + 1, keeping id, seq and colours. Inserted characters between survivors join the range and edge inserts stay outside it.
7. 7. Internal snapping: a start between a high and low surrogate moves back by 1, an end there moves forward by 1. Use it in applyTextStyle, clearTextStyle and getTextStyleRuns.
8. 8. Internal nextSeq(state) = 1 + highest seq across ranges and cleared, 1 when both are empty.
9. 9. withTextStyles writes both fields onto the passed object in place and `delete`s a field whose list is empty, then returns it. It is only for fresh copies and elements being mutated; cast through Mutable internally.
10. 10. createTextStyleRanges: return undefined for undefined or empty input. For each input at index i run sanitizeRange with id = input.id ?? randomId() and seq = input.seq ?? i + 1. Pass the survivors through resolveState with no cleared entries and return the list, or undefined when none survive.
11. 11. applyTextStyle: clamp the selection to originalText and snap it; if start >= end return the current state. A current range fully inside the selection whose every set attribute is also set by `style` is removed with a cleared entry {id, seq}. Append a new range {id: randomId(), seq: nextSeq, start, end, ...style}, where seq is computed before anything is removed. Return resolveState.
12. 12. clearTextStyle: clamp and snap as rule 11. For each range overlapping the selection that sets `attribute`: remove it with a cleared entry {id, seq} and add, each with a new randomId() and the original seq, the left piece [range.start, start) and the right piece [end, range.end) when non-empty with all its colours, and the middle piece with `attribute` removed when another attribute remains. Return resolveState.
13. 13. remapTextStyles: return null when the element has no ranges or nextOriginalText === element.originalText. Default branch: map each range with alignText(originalText, next, opts?.caret) and mapRange, dropping nulls with no cleared entry. When opts?.replace is true use no LCS: take suffix then prefix as in rule 5 with no caret, prevEnd = prev.length - suffix, nextEnd = next.length - suffix, delta = next.length - prev.length; start stays if <= prefix, gains delta if >= prevEnd, else becomes prefix; end stays if <= prefix, gains delta if >= prevEnd, else becomes nextEnd. A range left with start >= end is dropped. Return resolveState(mapped, element.clearedTextStyleRanges ?? []).
14. 14. sanitizeTextStyles: return the element itself when both fields are undefined. Treat a non-array field as empty. sanitizeRange each range against originalText.length, keep cleared entries that are objects with a non-empty string id of at most 64 characters and a positive safe integer seq, rebuilt with only those two keys. Return withTextStyles({ ...element }, resolveState(...)).
15. 15. mergeTextStyles(winner, loser): return winner when winner === loser, or when neither has ranges or cleared entries. Build cleared as the concatenation of both. For each id across both range lists: take the winner's range if present, with seq = the higher of both sides' seq; otherwise take the loser's range mapped with alignText(loser.originalText, winner.originalText) and mapRange, built once and only if the texts differ, dropping a null with no cleared entry. Then resolveState. If the result equals the winner's own lists field by field return winner; otherwise return withTextStyles({ ...winner }, state). Never touch version, versionNonce or updated.
16. 16. Module-level `const mergedRangeVersions = new Map<string, number>();` with a comment on why: the store's snapshot compares versions, so it cannot see a merge. noteMergedTextStyles(local, merged): for every id in exactly one of local's and merged's range lists, set mergedRangeVersions[id] = local.version.
17. 17. omitMergedTextStyleChanges(deleted, inserted) mutates the two partials: return unless deleted.version is a number and a textStyleRanges list exists on either. Remove from each list every id that is not in the other list and has mergedRangeVersions.get(id) >= deleted.version. When both lists end up empty, delete the textStyleRanges key from both.
18. 18. applyTextStyleDelta(element, nextOriginalText, removed, added): return null when both lists are empty or undefined and the text is unchanged. Start from remapTextStyles(element, nextOriginalText)?.ranges ?? element's ranges ?? []. For an id in removed and not in added: if present, take it out and add a cleared entry {id, seq}. For each entry of added: let t be the cleared entry of that id; if t.seq >= entry.seq use seq = t.seq + 1 and remove t; clamp offsets to nextOriginalText.length, skip it if start >= end, and replace any range of that id. Return resolveState.
19. 19. getTextStyleRuns(text, textStart, ranges): a range's local span is its offsets minus textStart, clamped to [0, text.length] and snapped against text. Collect 0, text.length and every span's edges, sorted and unique. For each segment walk `ranges` in order; every range whose span covers the segment overrides color when it sets color and highlight when it sets highlight. Merge adjacent segments of equal style. Runs hold local offsets and cover the whole text. A run has a colour key only when that colour is set. Empty text returns [].
20. 20. getStyledTextLines: return null when element.textStyleRanges is undefined; this is the only work unstyled text does. Split element.text.replace(/\r\n?/g, "\n") on \n. Keep a cursor into originalText, starting at 0. For a non-empty line find start = originalText.indexOf(line, cursor); return null for the whole element if start is -1 or any character in [cursor, start) is not whitespace; an empty line uses start = cursor. Set cursor = start + line.length. Entry for the line: null if it is empty, if hasRTLChars(line), or if no run from getTextStyleRuns(line, start, ranges) has a colour or highlight; otherwise the runs.
21. 21. layoutTextStyleRuns: font = getFontString(element); lineWidth = getLineWidth(lineText, font, renderEnvironment); lineStart = (element.width - lineWidth) / 2 for center, element.width - lineWidth for right, else 0. For each run x = lineStart + getLineWidth(lineText.slice(0, run.start), font, renderEnvironment), and width is the same measure of lineText.slice(0, run.end) minus that of the prefix, skipping the measure for an empty prefix.
