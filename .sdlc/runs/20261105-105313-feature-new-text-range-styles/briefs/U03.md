4. 4. getUniformTextRangeStyle(ranges, start, end, key): for a non-empty selection [start, end], return the string value of key ("color" | "highlight") if and only if every code unit in [start, end) is covered by ranges with the exact same non-empty value for key; otherwise return null.
5. 5. shiftTextRangesAtOffset(ranges, offset, deletedLength, insertedLength, nextTextLength): if !ranges?.length return undefined; for pure insertion (deletedLength === 0 && insertedLength > 0), ranges with start >= offset shift both start and end by +insertedLength, ranges with start < offset && offset <= end (strictly containing offset or ending at offset) keep start and extend end by +insertedLength, and ranges with end < offset are unchanged; for deletion or replacement (deletedLength > 0), first apply deletion of [offset, offset + deletedLength) by mapping any boundary x <= offset to x, x >= offset + deletedLength to x - deletedLength, and offset < x < offset + deletedLength to offset (dropping ranges that collapse to start >= end unless the original range strictly enclosed [offset, offset + deletedLength) and insertedLength > 0), then if insertedLength > 0 apply the pure insertion rule at offset (extending ranges where start < offset && offset <= end and shifting ranges where start >= offset by +insertedLength); finally normalize with normalizeTextRanges(result, nextTextLength).
