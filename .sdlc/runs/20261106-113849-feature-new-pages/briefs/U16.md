### U05 — edit `packages/element/src/Scene.ts` (codegen)

Behaviour: Scopes the Scene's existing element getters to the active page while keeping every other page's elements, and adds page switching and all-pages getters.

Rules:
1. New private fields: `activePageId: string | null = null`, `otherPagesElements: Map<string, OrderedExcalidrawElement>` (element id to element, elements of every page except the active one), and lazily built caches `allPagesElements: readonly OrderedExcalidrawElement[] | null` and `allPagesElementsMap: SceneElementsMap | null`, reset to null by every replaceAllElements and setActivePage.
2. While `activePageId` is null the Scene behaves exactly as today: nothing is stamped, `otherPagesElements` stays empty and the all-pages getters return the same array/map as the active ones.
3. `replaceAllElements(next, options?: { skipValidation?: true; allPages?: true })`: first stamp every element whose `pageId` is undefined with `activePageId` by direct assignment through `Mutable<ExcalidrawElement>` (no version bump); with `allPages` clear `otherPagesElements` first; then elements whose `pageId` differs from `activePageId` are set into `otherPagesElements` (an upsert; existing other-page elements not passed are kept), and an id that now belongs to the active page is deleted from `otherPagesElements`; the remaining active-page elements, in input order, go through the existing validation, `syncInvalidIndices` and map/frame/non-deleted rebuild; with `allPages`, also run `syncInvalidIndices` over the other-page elements; finally `triggerUpdate()`.
4. `setActivePage(pageId)` is a no-op when `pageId === activePageId`; otherwise it takes `getAllPagesElementsIncludingDeleted()`, sets `activePageId`, stamps undefined `pageId`s with the new id, rebuilds `otherPagesElements` from elements of other pages, orders the new page's elements with `orderByFractionalIndex` on a copy, clears the selection cache and calls `replaceAllElements` with them (with skipValidation).
5. `getAllPagesElementsIncludingDeleted()` returns the other pages' elements in `otherPagesElements` insertion order followed by the active page's elements; `getAllPagesElementsMapIncludingDeleted()` returns a `SceneElementsMap` of the same elements; both are cached until the next change.
6. `getActivePageId()` returns `activePageId`.
7. `destroy()` also clears `otherPagesElements`, resets both caches to null and sets `activePageId` to null.

Exports:

- `method Scene.replaceAllElements(nextElements: ElementsMapOrArray, options: { skipValidation?: true; allPages?: true } | undefined): void`
