### U02 — create `packages/element/src/pages.ts` (codegen)

Behaviour: Pure helpers for the page model: defaults, ordering, create/rename/move/delete, restore, reconcile and element-page repair.

Rules:
1. Imports: `generateKeyBetween` from `@excalidraw/fractional-indexing`; `randomId`, `randomInteger`, `arrayToMap` from `@excalidraw/common`; `isBoundToContainer`, `isBindingElement`, `isFrameLikeElement` from `./typeChecks`; types from `./types`. Every function is pure and never mutates its arguments.
2. `DEFAULT_PAGE_ID = "page-1"`, `DEFAULT_PAGE_NAME = "Page 1"`; `getDefaultPage()` returns `{ id: DEFAULT_PAGE_ID, name: DEFAULT_PAGE_NAME, index: "a0", version: 1, versionNonce: 0, isDeleted: false }` (deterministic so independent clients converge).
3. `getVisiblePages(pages)` returns the non-deleted pages sorted by `index` ascending, ties broken by `id` ascending.
4. `getActivePage(pages, activePageId)` returns the visible page with that id, else the first visible page, else null.
5. `getPageElements(elements, pageId)` returns the elements whose `pageId` equals `pageId`, in input order.
6. `getNewPageName(pages, formatName)` calls `formatName(n)` starting at n = visible page count + 1 and increments n while a visible page already has that exact name.
7. `createPage(pages, name, id?)` appends `{ id: id ?? randomId(), name, index: generateKeyBetween(lastVisible?.index ?? null, null), version: 1, versionNonce: randomInteger(), isDeleted: false }` and returns `{ pages: [...pages, page], page }`.
8. A page update (rename, move, delete) returns a new page object with `version + 1` and a new `randomInteger()` versionNonce, and a new array with that page replaced in place.
9. `renamePage(pages, pageId, name)` trims the name; when the trimmed name is empty, the page is missing or deleted, or the name is unchanged, it returns the same `pages` reference.
10. `movePage(pages, pageId, direction)` works on `getVisiblePages`: when the page is first and direction is -1, or last and direction is 1, it returns the same reference; otherwise the page's new index is `generateKeyBetween` of the two neighbours around its target slot (null at either end).
11. `deletePage(pages, pageId)` returns the same reference when the page is missing, already deleted, or the only visible page; otherwise it tombstones the page (`isDeleted: true`).
12. `getAdjacentPageId(pages, pageId)` returns the id of the visible page after `pageId`, else the one before, else null (computed on the visible order before any deletion).
13. `getPagesVersion(pages)` returns the sum of page versions.
14. `restorePages(pages: unknown)` keeps only array entries that are objects with a non-empty string `id`; keeps the first entry of each duplicate id; defaults `name` to `Page N` (N = 1-based position) when not a non-empty string, `index` via `generateKeyBetween(previousIndex, null)` when not a string, `version` to 1 and `versionNonce` to 0 when not finite numbers, `isDeleted` to `entry.isDeleted === true`; when no visible page remains it appends `getDefaultPage()` (with a fresh index after the last one when the default id is already taken, replacing the tombstone with the same id instead); the result is sorted by index then id.
15. `restoreActivePageId(pages, activePageId: unknown)` returns `activePageId` when it is a string id of a visible page, else the first visible page's id.
16. `reconcilePages(localPages, remotePages)` unions by id; for an id on both sides, the higher version wins and equal versions keep the one with the lower versionNonce; the result is sorted by index then id.
17. `repairElementPages(elements, pages, activePageId)` returns a new array: an element whose `pageId` is not a string or names no page in `pages` (tombstones count as existing) becomes `{ ...element, pageId: activePageId }`; then, using a map of the resulting elements, a bound text element (`isBoundToContainer`) takes its container's `pageId`, an element whose `frameId` refers to an element on another page gets `frameId: null`, a binding element whose `startBinding`/`endBinding` refers to an element on another page gets that binding set to null, and `boundElements` entries referring to elements on another page are removed; elements needing no change are returned as the same object; no version is bumped.
