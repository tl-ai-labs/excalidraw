## Decisions

- getLassoSelectedElementIds mode parameter and default: Accept optional boxSelectionMode?: BoxSelectionMode defaulting to "contain" on getLassoSelectedElementIds input, and pass this.app.state.boxSelectionMode from LassoTrail.updateSelection (not Defaulting boxSelectionMode to "overlap" in getLassoSelectedElementIds; not Reading window.h.state directly inside getLassoSelectedElementIds) — Aligns getLassoSelectedElementIds with getElementsWithinSelection (which defaults boxSelectionMode to "contain") while keeping utils.ts pure and testable.
- Full outline containment and frame-child clipping in Wrap ("contain") mode: Require every segment endpoint of the element outline (and its positioned bound text outline if present) to lie inside the closed lasso polygon via polygonIncludesPointNonZero AND require intersectionTest to be false while skipping standalone bound text elements; when an element belongs to an overlapping containing frame (getContainingFrame + elementOverlapsWithFrame), clip its AABB, outline segments, and intersection hits to the frame bounds in "contain" mode while keeping "overlap" mode unclipped (not Testing unclipped outline points of frame children in "contain" mode; not Testing only element AABB corners against the lasso polygon; not Testing only segment points without checking lasso edge intersections) — Matches elementsOverlappingBBox frame-clipping semantics so only the visible portion of a frame child inside its frame must be enclosed in Wrap mode, while preserving exact shape outline containment and leaving Overlap behaviour unchanged.
- Group resolution in Wrap ("contain") vs Overlap ("overlap") mode: In LassoTrail.selectElementsFromIds, when prevState.boxSelectionMode === "contain", group non-deleted selectable (!locked && !isBoundToContainer) scene elements by top-level groupId (element.groupIds.at(-1)) and delete any selected element whose top-level group members are not all present in nextSelectedElementIds before calling selectGroupsForSelectedElements (not Letting selectGroupsForSelectedElements expand partially enclosed groups in contain mode; not Including locked or bound-text elements in top-level group membership counts) — Matches elementsOverlappingBBox "contain" group post-processing so partially enclosed groups are dropped and bound text or locked elements do not prevent group selection.

Behaviour: Extend getLassoSelectedElementIds with a boxSelectionMode parameter supporting full outline, bound-text, and frame-clipped enclosure in Wrap ("contain") mode while preserving existing Overlap ("overlap") behaviour.

Rules:
1. 1. Import elementOverlapsWithFrame, getContainingFrame, getElementLineSegments, isBoundToContainer, and pointInsideBoundsInclusive from "@excalidraw/element", lineSegmentIntersectionPoints and pointFrom from "@excalidraw/math", type LineSegment from "@excalidraw/math/types", and type BoxSelectionMode from "../types".

3. 3. In getLassoSelectedElementIds loop over unlockedElements, when boxSelectionMode === "contain" and isBoundToContainer(element) is true, skip the element so standalone bound text never selects a partially enclosed container.
4. 4. For each candidate element in "contain" mode, check const associatedFrame = getContainingFrame(element, elementsMap) and when associatedFrame && elementOverlapsWithFrame(element, associatedFrame, elementsMap), compute frameBounds = getElementBounds(associatedFrame, elementsMap) and clip elementBounds to [Math.max(elementBounds[0], frameBounds[0]), Math.max(elementBounds[1], frameBounds[1]), Math.min(elementBounds[2], frameBounds[2]), Math.min(elementBounds[3], frameBounds[3])] as Bounds (matching elementsOverlappingBBox); in "overlap" mode leave frameBounds = null and elementBounds unclipped.
5. 5. Keep the fast AABB pre-filter doBoundsIntersect(lassoBounds, elementBounds) && !intersectedElements.has(element.id) && !enclosedElements.has(element.id).
6. 6. When boxSelectionMode === "contain", add element.id to enclosedElements if and only if enclosureTest(path, element, elementsSegments, elementsMap, "contain", frameBounds, elementBounds) is true AND !intersectionTest(path, element, elementsMap, elementsSegments.get(element.id), frameBounds) is true; do not add anything to intersectedElements in "contain" mode.
7. 7. When boxSelectionMode === "overlap", preserve exact existing behaviour: if enclosureTest(path, element, elementsSegments, elementsMap, "overlap") is true add element.id to enclosedElements, else if intersectionTest(path, element, elementsMap) is true add element.id to intersectedElements.
8. 8. Implement a helper clipSegmentToBounds([p0, p1]: LineSegment<GlobalPoint>, [minX, minY, maxX, maxY]: Bounds): LineSegment<GlobalPoint> | null using Liang-Barsky parameter clipping on [0, 1] against [minX, minY, maxX, maxY], and clipSegmentsToBounds(segments, bounds) returning the non-null clipped segments.
9. 9. In enclosureTest(lassoPath, element, elementsSegments, elementsMap, mode = "overlap", frameBounds = null, clippedElementBounds?): resolve rawSegments = elementsSegments.get(element.id) ?? getElementLineSegments(element, elementsMap); if !rawSegments || rawSegments.length === 0 return false; when mode === "overlap" return rawSegments.some((segment) => segment.some((point) => polygonIncludesPointNonZero(point, lassoPolygon))).
10. 10. In enclosureTest when mode === "contain", if frameBounds is non-null, clip rawSegments via clipSegmentsToBounds(rawSegments, frameBounds) (falling back to the 4 boundary segments of clippedElementBounds if all outline segments lie outside frameBounds because the element surrounds the frame), and require every segment endpoint to satisfy polygonIncludesPointNonZero(point, lassoPolygon); additionally, if getBoundTextElement(element, elementsMap) returns a boundTextElement, construct positionedBoundText = { ...boundTextElement, ...computeBoundTextPosition(element, boundTextElement, elementsMap) }, compute boundTextSegments = frameBounds ? clipSegmentsToBounds(getElementLineSegments(positionedBoundText, elementsMap), frameBounds) : getElementLineSegments(positionedBoundText, elementsMap), and require every endpoint in boundTextSegments (when non-empty, or when frameBounds is null require boundTextSegments.length > 0) to satisfy polygonIncludesPointNonZero(point, lassoPolygon).
11. 11. In intersectionTest(lassoPath, element, elementsMap, elementSegments?, frameBounds = null), when frameBounds is null keep existing intersectElementWithLineSegment(..., 0, true) checks on element and positioned boundTextElement plus elementSegments.some((seg) => lineSegmentIntersectionPoints(lassoSegment, seg) !== null) when elementSegments is provided; when frameBounds is non-null, call intersectElementWithLineSegment(..., 0, false) on element and positioned boundTextElement and only count hits where pointInsideBoundsInclusive(hit, frameBounds) is true, and clip elementSegments with clipSegmentsToBounds(elementSegments, frameBounds) before testing lineSegmentIntersectionPoints.
