## Decisions

- Default value and type of boxSelectionMode in getLassoSelectedElementIds: Accept optional boxSelectionMode?: "contain" | "overlap" defaulting to "overlap" when omitted. (not Defaulting boxSelectionMode to "contain" in getLassoSelectedElementIds; not Importing AppState from ../types) — Defaulting to "overlap" preserves backwards compatibility for existing direct callers of getLassoSelectedElementIds, while literal union "contain" | "overlap" matches AppState["boxSelectionMode"] without importing off-limits ../types.
- Contain vs overlap geometry evaluation in getLassoSelectedElementIds: In "contain" mode, select an element only when enclosureTest returns true (all points of all element segments, and any bound text segments, are inside lassoPolygon via polygonIncludesPointNonZero) and intersectionTest returns false; in "overlap" mode, select when enclosureTest returns true (any segment point inside lassoPolygon) or intersectionTest returns true. (not Checking only element bounding box corners in contain mode; not Skipping intersectionTest in contain mode when segment endpoints are inside the lasso polygon) — A concave lasso or a lasso crossing curved/long edges can include all segment endpoints while still intersecting the element outline; requiring both all segment points inside and zero outline intersections ensures true full enclosure across all shapes.
- Bound text handling in getLassoSelectedElementIds: Skip bound text elements (isBoundToContainer(element) whose containerId is in elementsMap) as standalone candidates, and include a container's bound text segments and bounds in the container's own contain/overlap evaluation. (not Evaluating bound text independently in the element loop during contain mode) — In contain mode, a lasso enclosing only bound text inside a container must not select the container via LassoTrail.selectElementsFromIds; in overlap mode, touching or enclosing bound text selects the container.

### U01 — edit `packages/excalidraw/lasso/utils.ts` (codegen)

Behaviour: Make getLassoSelectedElementIds honour boxSelectionMode ("contain" vs "overlap") across all shape types and bound text.

Rules:
1. 1. Import isBoundToContainer from @excalidraw/element alongside existing @excalidraw/element value imports.
2. 2. Add optional property boxSelectionMode?: "contain" | "overlap" to the input parameter type of getLassoSelectedElementIds and default it to "overlap" when destructuring input.
3. 3. In the unlockedElements loop, skip standalone evaluation of bound text elements whose container exists in elementsMap: if (isBoundToContainer(element) && elementsMap.has(element.containerId)) { continue; }.
4. 4. Look up const boundTextElement = getBoundTextElement(element, elementsMap); and compute bounds intersection as doBoundsIntersect(lassoBounds, elementBounds) || (boxSelectionMode !== "contain" && !!boundTextElement && doBoundsIntersect(lassoBounds, getElementBounds(boundTextElement, elementsMap))).
5. 5. When boxSelectionMode === "contain", add element.id to enclosedElements if and only if enclosureTest(path, element, elementsSegments, elementsMap, boxSelectionMode) && !intersectionTest(path, element, elementsMap) is true; never add to intersectedElements in "contain" mode.
6. 6. When boxSelectionMode !== "contain", preserve existing overlap logic: if enclosureTest(path, element, elementsSegments, elementsMap, boxSelectionMode) is true add element.id to enclosedElements, else if intersectionTest(path, element, elementsMap) is true add element.id to intersectedElements.
7. 7. Update enclosureTest(lassoPath, element, elementsSegments, elementsMap, boxSelectionMode = "overlap") to return false if !segments || segments.length === 0; in "contain" mode require every point of every segment in segments (and in elementsSegments.get(boundTextElement.id) when boundTextElement has non-empty segments) to satisfy polygonIncludesPointNonZero(point, lassoPolygon); in "overlap" mode return true if any point of any segment in segments (or in boundTextElement's segments when present) satisfies polygonIncludesPointNonZero(point, lassoPolygon).
