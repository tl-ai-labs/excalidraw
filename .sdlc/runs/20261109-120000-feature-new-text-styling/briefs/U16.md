### U16 — edit `packages/excalidraw/data/restore.ts` (codegen)

Behaviour: Restoring a text element writes a sanitised `styleRanges` only when at least one valid range survives; legacy input, an empty list and fully corrupt input restore with no `styleRanges` key.

Rules:
1. 1. Import `sanitizeTextStyleRanges` and `withoutStyleRanges` from `@excalidraw/element` in one import on its own line after the `refreshTextDimensions` import.
2. 2. After the `lineHeight` const in `case "text"`, compute `const styleRanges = sanitizeTextStyleRanges(element.styleRanges, (element.originalText || text).length);` so the clamp length is that of the restored originalText.
3. 3. Pass `withoutStyleRanges(element)` instead of `element` as the first argument of that restoreElementWithProperties call, because it spreads the raw input first and would otherwise carry an unsanitised or empty `styleRanges` through; the `extra` expressions keep reading `element`.
4. 4. In the `extra` object, after `originalText: element.originalText || text,` add `...(styleRanges.length ? { styleRanges } : {}),` so the key is written only when a range survives.
5. 5. Nothing else changes; untrusted input reaches the field only through this sanitiser.
