### U02 — create `packages/element/src/textStyleRanges.ts` (codegen)

Behaviour: Pure helpers for styled ranges: normalise, clamp, shift on edits, apply a style to a span, sanitise untrusted input, split wrapped text lines into styled runs, and drop an emptied `styleRanges` key from an element.

Rules:
1. 1. Import only `import type { TextStyleRange } from "./types";` — no other imports, no side effects, no mutation of inputs; every function returns new arrays of new range objects (except the documented same-reference returns of shiftRangesForEdit).
2. 2. Export `type TextStyleUpdate = { color?: string | null; backgroundColor?: string | null }` (key absent: keep; `null`: clear; string: set) and `type TextStyleRun = { text: string; color: string | null; backgroundColor: string | null }`.
3. 3. A style value counts as set only when it is a non-empty string; when building a range copy only the set keys (`color`, `backgroundColor`) onto the new object, never write `null`/`undefined` keys.
4. 4. normalizeRanges(ranges): drop entries whose start/end are not finite numbers, whose start >= end, or with no set style; copy kept entries; sort by start then end (stable); when an entry starts before the previous kept entry's end, move its start to that end and drop it if now empty; merge an entry into the previous one when previous.end === entry.start and both `color` and `backgroundColor` are equal (both unset counts as equal); always return a new array.
5. 5. clampRanges(ranges, textLength): map start/end to `Math.min(Math.max(value, 0), textLength)`, then return normalizeRanges of the result.
6. 6. shiftRangesForSplice(ranges, offset, deletedCount, insertedCount) with o = offset, d = deletedCount, i = insertedCount: start' = start < o ? start : start >= o + d ? start - d + i : o + i; end' = end <= o ? end : end >= o + d ? end - d + i : o; drop ranges with start' >= end'; return normalizeRanges of the result.
7. 7. shiftRangesForEdit(ranges, prevText, nextText): return `ranges` itself (same reference, possibly undefined) when ranges is undefined or empty or prevText === nextText; otherwise p = common prefix length, s = common suffix length capped at Math.min(prevText.length, nextText.length) - p, and return shiftRangesForSplice(ranges, p, prevText.length - p - s, nextText.length - p - s).
8. 8. applyStyleToRange(ranges, start, end, style): with start = Math.max(0, start), if start >= end return normalizeRanges(ranges). Otherwise split every range at start and end: pieces outside [start, end) keep their style; pieces inside get the merged style (per key: undefined keeps the range's value, null removes it, a string sets it); every gap inside [start, end) not covered by a range becomes a new piece carrying only the string values of `style`; return normalizeRanges of all pieces (which drops unstyled pieces and merges equal neighbours).
9. 9. sanitizeTextStyleRanges(input: unknown, textLength): non-array input returns []. Keep an entry only if it is a non-null object, `start` and `end` are integers (Number.isInteger) with start < end, and each of `color`/`backgroundColor` is absent, null, or a valid colour (string of 1 to 64 chars matching /^[#a-z0-9(),.%\s/-]+$/i and not matching /url\s*\(/i); an entry with an invalid colour is dropped whole; an entry with no valid style is dropped. Build fresh range objects from the kept fields and return clampRanges(kept, textLength).
10. 10. getTextStyleLineRuns(text, originalText, ranges): return null when ranges is undefined or empty. Clamp ranges to originalText.length. Split `text` on "\n". Line 0 starts at offset 0. For each later line, with c = end offset of the previous line: let nl = originalText.indexOf("\n", c); if nl !== -1 and originalText.slice(c, nl) is whitespace only, the line starts at nl + 1; otherwise it starts at the first index >= c whose character does not match /\s/. If originalText.startsWith(line, lineStart) is false, return null.
11. 11. For each aligned line [lineStart, lineStart + line.length), emit runs covering the whole line in order: consecutive segments between range boundaries clipped to the line, each `{ text, color, backgroundColor }` with unset styles as null; merge adjacent segments with equal styles; a line with no styled character (including an empty line) yields exactly one run `{ text: line, color: null, backgroundColor: null }`. Advance through the sorted ranges with a moving index so the whole call is O(lines + ranges).
12. 12. withoutStyleRanges(element): return `element` itself (same reference) when it has no own `styleRanges` key (`Object.prototype.hasOwnProperty.call`); otherwise return a shallow copy without that key (destructure `{ styleRanges: _, ...rest }`), with no version bump — callers pass the result to `newElementWith`.
13. 13. Give every export a one-paragraph JSDoc stating the offset base (`originalText`) and the boundary semantics of rule 6; withoutStyleRanges' JSDoc states the omit-when-empty rule (a stored `styleRanges` is never `[]`).
