### U04 — create `packages/element/src/textRangeMerge.ts` (codegen)

Behaviour: The pure, symmetric merge of two versions' ranges, and how a history delta is applied to ranges.

Rules:
1. Imports: randomId from @excalidraw/common; hashString from "."; isTextElement from ./typeChecks; mapTextSpan from ./textDiff; areTextRangesEqual, canonicalizeTextRanges, sanitizeTextRanges, shiftTextRanges from ./textRanges.
2. mergeTextRanges must read no clock, random source or module state and must never mutate its inputs. randomId is used only by applyTextRangesDelta.
3. mergeTextRanges step 1: return base if either element is not a text element, or if neither has textRanges. Elements with no ranges therefore reconcile as today, and the same object comes back (FR-20).
4. mergeTextRanges step 2: baseRanges = sanitizeTextRanges(base.textRanges, base.originalText)?.ranges ?? [], otherRanges = the same for other. Return base if otherRanges is empty.
5. getRegister(record, element) = record.origin ?? { version: element.version, versionNonce: element.versionNonce, text: element.originalText, start: record.start, end: record.end }.
6. pickNewerRegister(a, b): higher version wins; at equal version lower versionNonce wins; at equal nonce the smaller of (text, start, end) compared in that order wins, so a result is defined even for crafted input.
7. mergeTextRanges step 3, for every id in the union with bRec and oRec being its records: id, z, color and highlight come from bRec ?? oRec. retired is true if either side is retired, otherwise the key stays absent.
8. mergeTextRanges step 4, the position: if bRec exists and has no origin, use bRec.start and bRec.end with no origin. Otherwise register = pickNewerRegister over the registers of the records present, using base for bRec and other for oRec.
9. mergeTextRanges step 5: if register.version === base.version and register.versionNonce === base.versionNonce and register.text === base.originalText, use register.start and register.end with no origin. Otherwise use mapTextSpan(register.text, base.originalText, register.start, register.end) and set origin to register, whose fields are never changed.
10. mergeTextRanges step 6: keep collapsed records, never drop one here. ranges = canonicalizeTextRanges(records), next = { textHash: hashString(base.originalText), ranges }. If areTextRangesEqual(next, base.textRanges) return base. Otherwise return { ...base, textRanges: next }, built with a spread and not newElementWith, which would bump the version.
11. applyTextRangesDelta step 1: holdsText = typeof inserted.originalText === "string"; nextText = holdsText ? inserted.originalText : element.originalText; prior = sanitizeTextRanges(element.textRanges, element.originalText)?.ranges ?? [].
12. applyTextRangesDelta step 2: if nextText !== element.originalText, shifted = shiftTextRanges(element.originalText, nextText, element.textRanges)?.ranges ?? []; otherwise shifted = prior. Put shifted into a Map by id.
13. applyTextRangesDelta step 3: priorAlive = ids of deleted.textRanges?.ranges that are not retired, targetAlive = the same for inserted.textRanges?.ranges. Read these two arrays directly with Array.isArray, since a delta is local history data.
14. applyTextRangesDelta step 4: for each id in priorAlive and not in targetAlive, if the Map has it, set a copy with retired: true.
15. applyTextRangesDelta step 5: z = 1 + the highest z in the Map, or 1 if empty. For each record t of inserted.textRanges?.ranges that is not retired and whose id is not in priorAlive, in array order: let c = Map.get(t.id). If c exists and is not retired, skip it. The span is t's when holdsText, else c's if c exists, else t's, clamped to 0..nextText.length. If c is retired, add a new record with id: randomId(), the span, z: z++ (then advance z), and t's color and highlight. If c is absent, add t without origin, with the span.
16. applyTextRangesDelta step 6: if holdsText and deleted.originalText === element.originalText, then for each non-retired t in inserted.textRanges?.ranges whose Map entry exists and is not retired, set that entry's start and end to t's, clamped. This restores exact offsets when no other text change came in between.
17. applyTextRangesDelta step 7: next = { textHash: hashString(nextText), ranges: canonicalizeTextRanges(Map values) }. If element.textRanges is undefined and ranges is empty return undefined. If areTextRangesEqual(next, element.textRanges) return element.textRanges. Otherwise return next.
