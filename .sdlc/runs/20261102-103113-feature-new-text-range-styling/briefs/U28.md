### U03 — create `packages/element/src/textRanges.ts` (codegen)

Rules:

3. canonicalizeTextRanges: return a new array sorted by z ascending, then id ascending, comparing ids with < and > (never localeCompare). If longer than MAX_TEXT_RANGES keep only the last MAX_TEXT_RANGES entries.
4. Every record is written with keys in the order id, start, end, z, color, highlight, retired, origin, and with absent keys left out, not set to undefined.
5. areTextRangesEqual: both undefined is true, exactly one undefined is false, otherwise textHash equal, ranges lengths equal, and each index equal on id, start, end, z, color, highlight, retired and on every field of origin.
6. sanitizeTextRanges step 1: return undefined unless raw is an object with an array `ranges`. Return undefined if raw.textHash !== hashString(originalText). Read only the first MAX_TEXT_RANGES * 16 entries of ranges. Never throw.
7. sanitizeTextRanges step 2, per entry, dropping it if any check fails: it is a non-null object; id is a string of length 1 to 64 not already seen; start, end and z are integers (Number.isInteger); z >= 0; end >= start.
8. sanitizeTextRanges step 3: keep color only if it is null or isValidTextRangeColor, the same for highlight. Drop the entry if neither key remains.
9. sanitizeTextRanges step 4: clamp start and end to 0..originalText.length. Keep retired only when it is exactly true. Keep origin only when it is an object whose version and versionNonce are integers, whose text is a string, and whose start and end are integers with 0 <= start <= end <= text.length; otherwise leave it out.
10. sanitizeTextRanges step 5: keep a collapsed entry (start === end), with or without retired and origin: it is the tombstone of deleted characters, and restoreElements runs on every remote element before reconcile, so dropping it here would let a merge re-add it. 11. getTextStyleRuns step 1: textRanges = sanitizeTextRanges(element.textRanges, element.originalText); return [] if undefined. Use only records that are not retired and have start < end.
12. getTextStyleRuns step 2: for each of the attributes color and highlight build a list of records with that key present, sorted by z descending, then null values before strings, then id descending.
13. getTextStyleRuns step 3: bounds = sorted unique start and end values of the used records. For each consecutive pair [a, b) take, for each attribute, the first record in its list with start <= a and end >= b. Its value is the style, and no record or a null value means null.
14. getTextStyleRuns step 4: skip segments where both attributes are null, join adjacent segments with equal color and highlight, and return runs ascending. Runs are disjoint.
15. applyTextRangeStyle step 1: clamp span to 0..originalText.length, returning element.textRanges if start >= end. Normalize style: an attribute with a transparent string (isTransparent) becomes null; an attribute that is undefined or an invalid string is left out. Return element.textRanges if neither attribute remains.
16. applyTextRangeStyle step 2: current = sanitizeTextRanges(element.textRanges, element.originalText)?.ranges ?? []; z = 1 + the highest z in current, or 1 if empty. Every existing record loses its origin.
17. applyTextRangeStyle step 3, a removal: a record r is removed by this style when it is not retired, r.start < end and r.end > start (so a collapsed record never qualifies), it has at least one string attribute, and each of its string attributes is one whose value in style is null. A colour or highlight pick has no null, so it removes nothing, and a clear record has no string attribute, so it is never removed. Set retired: true on every removed r, keeping its offsets. If r.start < start, add a kept part { id: randomId(), start: r.start, end: start, z: r.z } with r's color and highlight keys as they are. If r.end > end, add a kept part { id: randomId(), start: end, end: r.end, z: r.z } the same way. A kept part never has retired or origin.
18. applyTextRangeStyle step 4: add { id: randomId(), start, end, z, ...style }. next = { textHash: hashString(element.originalText), ranges: canonicalizeTextRanges(all) }.
19. applyTextRangeStyle step 5: if getTextStyleRuns of the element and of { originalText, textRanges: next } are field-for-field equal, return element.textRanges, so a no-op adds nothing and an element that never had ranges stays without the key (FR-2). Otherwise return next.

21. shiftTextRanges step 2: hunks = diffText(oldText, newText), computed once. Map each record through mapSpanThroughHunks. Drop origin from every record. Keep every record whatever its span: a record whose span collapses stays collapsed and native, which is what stops a merge re-adding it from a peer's copy, and stops old text reaching origin (FR-3). Return { textHash: hashString(newText), ranges: canonicalizeTextRanges(mapped) }.

### U04 — create `packages/element/src/textRangeMerge.ts` (codegen)

Behaviour: The pure, symmetric merge of two versions' ranges, and how a history delta is applied to ranges.

Rules:
1. Imports: randomId from @excalidraw/common; hashString from "."; isTextElement from ./typeChecks; mapTextSpan from ./textDiff; areTextRangesEqual, canonicalizeTextRanges, sanitizeTextRanges, shiftTextRanges from ./textRanges.
2. mergeTextRanges must read no clock, random source or module state and must never mutate its inputs. randomId is used only by applyTextRangesDelta.
3. mergeTextRanges step 1: return base if either element is not a text element, or if neither has textRanges. Elements with no ranges therefore reconcile as today, and the same object comes back (FR-20).
4. mergeTextRanges step 2: baseRanges = sanitizeTextRanges(base.textRanges, base.originalText)?.ranges ?? [], otherRanges = the same for other. Return base if otherRanges is empty.
5. getRegister(record, element) = record.origin ?? { version: element.version, versionNonce: element.versionNonce, text: element.originalText, start: record.start, end: record.end }.
6. pickNewerRegister(a, b): higher version wins; at equal version lower versionNonce wins; at equal nonce the smaller of (text, start, end) compared in that order wins, so a result is defined even for crafted input.
7. mergeTextRanges step 3, for every id in the union with bRec and oRec being its records: id, z, color and highlight come from bRec ?? oRec. retired is true if either side is retired, otherwise the key stays absent.
8. mergeTextRanges step 4, the position: if bRec exists and has no origin, use bRec.start and bRec.end with no origin. Otherwise register = pickNewerRegister over the registers of the records present, using base for bRec and other for oRec.
9. mergeTextRanges step 5: if register.version === base.version and register.versionNonce === base.versionNonce and register.text === base.originalText, use register.start and register.end with no origin. Otherwise use mapTextSpan(register.text, base.originalText, register.start, register.end) and set origin to register, whose fields are never changed.
10. mergeTextRanges step 6: keep collapsed records, never drop one here. ranges = canonicalizeTextRanges(records), next = { textHash: hashString(base.originalText), ranges }. If areTextRangesEqual(next, base.textRanges) return base. Otherwise return { ...base, textRanges: next }, built with a spread and not newElementWith, which would bump the version.
11. applyTextRangesDelta step 1: holdsText = typeof inserted.originalText === "string"; nextText = holdsText ? inserted.originalText : element.originalText; prior = sanitizeTextRanges(element.textRanges, element.originalText)?.ranges ?? [].
12. applyTextRangesDelta step 2: if nextText !== element.originalText, shifted = shiftTextRanges(element.originalText, nextText, element.textRanges)?.ranges ?? []; otherwise shifted = prior. Put shifted into a Map by id.
13. applyTextRangesDelta step 3: priorAlive = ids of deleted.textRanges?.ranges that are not retired, targetAlive = the same for inserted.textRanges?.ranges. Read these two arrays directly with Array.isArray, since a delta is local history data.
14. applyTextRangesDelta step 4: for each id in priorAlive and not in targetAlive, if the Map has it, set a copy with retired: true.
15. applyTextRangesDelta step 5: for each record t of inserted.textRanges?.ranges that is not retired and whose id is not in priorAlive, in array order: let c = Map.get(t.id). If c exists and is not retired, skip it. The span is t's when holdsText, else c's if c exists, else t's, clamped to 0..nextText.length. If c is retired, add a new record with id: randomId(), the span, t's z, and t's color and highlight, so undoing a removal restores the layer order. If c is absent, add t without origin, with the span.
16. applyTextRangesDelta step 6: exact = holdsText and deleted.originalText === element.originalText. addressed = inserted.textRanges?.textHash === hashString(nextText). For each non-retired t in inserted.textRanges?.ranges whose Map entry exists and is not retired, set that entry's start and end to t's, clamped, when exact is true, or when addressed is true and both the entry and the record of the same id in deleted.textRanges?.ranges are collapsed (start === end). The first restores exact offsets when no other text change came in between. The second gives a word its range back when the step being undone is the one that lost the word, because t's offsets address that text. Any other collapsed record stays collapsed (FR-3).
17. applyTextRangesDelta step 7: next = { textHash: hashString(nextText), ranges: canonicalizeTextRanges(Map values) }. If element.textRanges is undefined and ranges is empty return undefined. If areTextRangesEqual(next, element.textRanges) return element.textRanges. Otherwise return next.
