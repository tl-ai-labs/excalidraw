3. canonicalizeTextRanges: return a new array sorted by z ascending, then id ascending, comparing ids with < and > (never localeCompare). If longer than MAX_TEXT_RANGES keep only the last MAX_TEXT_RANGES entries.
4. Every record is written with keys in the order id, start, end, z, color, highlight, retired, origin, and with absent keys left out, not set to undefined.
5. areTextRangesEqual: both undefined is true, exactly one undefined is false, otherwise textHash equal, ranges lengths equal, and each index equal on id, start, end, z, color, highlight, retired and on every field of origin.
6. sanitizeTextRanges step 1: return undefined unless raw is an object with an array `ranges`. Return undefined if raw.textHash !== hashString(originalText). Read only the first MAX_TEXT_RANGES * 16 entries of ranges. Never throw.
7. sanitizeTextRanges step 2, per entry, dropping it if any check fails: it is a non-null object; id is a string of length 1 to 64 not already seen; start, end and z are integers (Number.isInteger); z >= 0; end >= start.
8. sanitizeTextRanges step 3: keep color only if it is null or isValidTextRangeColor, the same for highlight. Drop the entry if neither key remains.
9. sanitizeTextRanges step 4: clamp start and end to 0..originalText.length. Keep retired only when it is exactly true. Keep origin only when it is an object whose version and versionNonce are integers, whose text is a string, and whose start and end are integers with 0 <= start <= end <= text.length; otherwise leave it out.
10. sanitizeTextRanges step 5: keep a collapsed entry (start === end), with or without retired and origin: it is the tombstone of deleted characters, and restoreElements runs on every remote element before reconcile, so dropping it here would let a merge re-add it. Then canonicalizeTextRanges. Return undefined if nothing remains. If the result equals raw (areTextRangesEqual) return raw itself, else return { textHash: raw.textHash, ranges }.
11. getTextStyleRuns step 1: textRanges = sanitizeTextRanges(element.textRanges, element.originalText); return [] if undefined. Use only records that are not retired and have start < end.
12. getTextStyleRuns step 2: for each of the attributes color and highlight build a list of records with that key present, sorted by z descending, then null values before strings, then id descending.
13. getTextStyleRuns step 3: bounds = sorted unique start and end values of the used records. For each consecutive pair [a, b) take, for each attribute, the first record in its list with start <= a and end >= b. Its value is the style, and no record or a null value means null.
14. getTextStyleRuns step 4: skip segments where both attributes are null, join adjacent segments with equal color and highlight, and return runs ascending. Runs are disjoint.
15. applyTextRangeStyle step 1: clamp span to 0..originalText.length, returning element.textRanges if start >= end. Normalize style: an attribute with a transparent string (isTransparent) becomes null; an attribute that is undefined or an invalid string is left out. Return element.textRanges if neither attribute remains.
16. applyTextRangeStyle step 2: current = sanitizeTextRanges(element.textRanges, element.originalText)?.ranges ?? []; z = 1 + the highest z in current, or 1 if empty. Every existing record loses its origin.
17. applyTextRangeStyle step 3, a removal: a record r is removed by this style when it is not retired, r.start < end and r.end > start (so a collapsed record never qualifies), it has at least one string attribute, and each of its string attributes is one whose value in style is null. A colour or highlight pick has no null, so it removes nothing, and a clear record has no string attribute, so it is never removed. Set retired: true on every removed r, keeping its offsets. If r.start < start, add a kept part { id: randomId(), start: r.start, end: start, z: r.z } with r's color and highlight keys as they are. If r.end > end, add a kept part { id: randomId(), start: end, end: r.end, z: r.z } the same way. A kept part never has retired or origin.
18. applyTextRangeStyle step 4: add { id: randomId(), start, end, z, ...style }. next = { textHash: hashString(element.originalText), ranges: canonicalizeTextRanges(all) }.
19. applyTextRangeStyle step 5: if getTextStyleRuns of the element and of { originalText, textRanges: next } are field-for-field equal, return element.textRanges, so a no-op adds nothing and an element that never had ranges stays without the key (FR-2). Otherwise return next.
20. shiftTextRanges step 1: return textRanges if it is undefined or oldText === newText. current = sanitizeTextRanges(textRanges, oldText); if undefined return textRanges unchanged, which stays stale and ignored.
21. shiftTextRanges step 2: hunks = diffText(oldText, newText), computed once. Map each record through mapSpanThroughHunks. Drop origin from every record. Keep every record whatever its span: a record whose span collapses stays collapsed and native, which is what stops a merge re-adding it from a peer's copy, and stops old text reaching origin (FR-3). Return { textHash: hashString(newText), ranges: canonicalizeTextRanges(mapped) }.
22. getTextRangesUpdate: return {} if element.textRanges is undefined or nextOriginalText === element.originalText; otherwise { textRanges: shiftTextRanges(element.originalText, nextOriginalText, element.textRanges) }.
