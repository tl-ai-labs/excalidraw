### U02 — create `packages/element/src/textDiff.ts` (codegen)

Behaviour: Pure diff between two strings as hunks, and mapping of a range's start and end through those hunks.

Rules:
1. Exact constants: MIN_MATCH_LENGTH = 3, MAX_DIFF_CELLS = 1_000_000. No clock, no randomness, no module state.
2. diffText step 1: if oldText === newText return [].
3. diffText step 2: prefix = length of the common leading code units. If prefix > 0 and oldText.charCodeAt(prefix - 1) is a high surrogate (0xD800 to 0xDBFF), subtract 1.
4. diffText step 3: suffix = length of the common trailing code units, never more than Math.min(oldText.length, newText.length) - prefix. If suffix > 0 and oldText.charCodeAt(oldText.length - suffix) is a low surrogate (0xDC00 to 0xDFFF), subtract 1.
5. diffText step 4: a = oldText.slice(prefix, oldText.length - suffix), b = newText.slice(prefix, newText.length - suffix), n = a.length, m = b.length. If n === 0, or m === 0, or n * m > MAX_DIFF_CELLS, return one hunk { oldStart: prefix, oldEnd: prefix + n, newStart: prefix, newEnd: prefix + m }.
6. diffText step 5: fill a Uint16Array of (n + 1) * (m + 1) cells where cell (i, j) is the longest common subsequence length of a.slice(i) and b.slice(j), computed from i = n - 1 and j = m - 1 downwards: if a[i] === b[j] then cell(i, j) = 1 + cell(i + 1, j + 1), else Math.max(cell(i + 1, j), cell(i, j + 1)).
7. diffText step 6: walk i = 0, j = 0 while i < n and j < m. If a[i] === b[j], record the pair (i, j) and advance both. Otherwise, if cell(i + 1, j) >= cell(i, j + 1) advance i, else advance j.
8. diffText step 7: group pairs into blocks: a block is a maximal run where i and j both rise by 1. Drop every block shorter than MIN_MATCH_LENGTH.
9. diffText step 8: walk kept blocks with cursors ai = 0, bi = 0. Before each block, if ai < block's i start or bi < block's j start, push a hunk spanning the gap with prefix added to all four numbers, then move ai and bi past the block. After the last block, if ai < n or bi < m push the final hunk. With no kept blocks this is one hunk for the whole middle. Hunks are ascending and never touch.
10. mapSpanThroughHunks: nextStart = mapStart(start), nextEnd = mapEnd(end), and return { start: nextStart, end: Math.max(nextStart, nextEnd) }.
11. mapStart(p): delta = 0; for each hunk in order: if p < hunk.oldStart stop; if p <= hunk.oldEnd return hunk.newEnd; delta = hunk.newEnd - hunk.oldEnd. Return p + delta. So an insertion exactly at a range's start moves the start past the inserted text.
12. mapEnd(p): delta = 0; for each hunk in order: if p <= hunk.oldStart stop; if p <= hunk.oldEnd return hunk.newStart; delta = hunk.newEnd - hunk.oldEnd. Return p + delta. So an insertion exactly at a range's end leaves the end where it is.
13. mapTextSpan: mapSpanThroughHunks(diffText(oldText, newText), start, end).

Exports:

- `function diffText(oldText: string, newText: string): TextHunk[]`
- `function mapSpanThroughHunks(hunks: readonly TextHunk[], start: number, end: number): { start: number; end: number }`
- `function mapTextSpan(oldText: string, newText: string, start: number, end: number): { start: number; end: number }`

4. mergeTextRanges step 2: baseRanges = sanitizeTextRanges(base.textRanges, base.originalText)?.ranges ?? [], otherRanges = the same for other. Return base if otherRanges is empty.
5. getRegister(record, element) = record.origin ?? { version: element.version, versionNonce: element.versionNonce, text: element.originalText, start: record.start, end: record.end }.
6. pickNewerRegister(a, b): higher version wins; at equal version lower versionNonce wins; at equal nonce the smaller of (text, start, end) compared in that order wins, so a result is defined even for crafted input.
7. mergeTextRanges step 3, for every id in the union with bRec and oRec being its records: id, z, color and highlight come from bRec ?? oRec. retired is true if either side is retired, otherwise the key stays absent.
8. mergeTextRanges step 4, the position: if bRec exists and has no origin, use bRec.start and bRec.end with no origin. Otherwise register = pickNewerRegister over the registers of the records present, using base for bRec and other for oRec.
9. mergeTextRanges step 5: if register.version === base.version and register.versionNonce === base.versionNonce and register.text === base.originalText, use register.start and register.end with no origin. Otherwise use mapTextSpan(register.text, base.originalText, register.start, register.end) and set origin to register, whose fields are never changed.
10. mergeTextRanges step 6: keep collapsed records, never drop one here. ranges = canonicalizeTextRanges(records), next = { textHash: hashString(base.originalText), ranges }. If areTextRangesEqual(next, base.textRanges) return base. Otherwise return { ...base, textRanges: next }, built with a spread and not newElementWith, which would bump the version.
11. applyTextRangesDelta step 1: holdsText = typeof inserted.originalText === "string"; nextText = holdsText ? inserted.originalText : element.originalText; prior = sanitizeTextRanges(element.textRanges, element.originalText)?.ranges ?? [].
12. applyTextRangesDelta step 2: if nextText !== element.originalText, shifted = shiftTextRanges(element.originalText, nextText, element.textRanges)?.ranges ?? []; otherwise shifted = prior. Put shifted into a Map by id.
13. applyTextRangesDelta step 3: priorAlive = ids of deleted.textRanges?.ranges that are not retired, targetAlive = the same for inserted.textRanges?.ranges. Read these two arrays directly with Array.isArray, since a delta is local history data.
14. applyTextRangesDelta step 4: for each id in priorAlive and not in targetAlive, if the Map has it, set a copy with retired: true.
15. applyTextRangesDelta step 5: z = 1 + the highest z in the Map, or 1 if empty. For each record t of inserted.textRanges?.ranges that is not retired and whose id is not in priorAlive, in array order: let c = Map.get(t.id). If c exists and is not retired, skip it. The span is t's when holdsText, else c's if c exists, else t's, clamped to 0..nextText.length. If c is retired, add a new record with id: randomId(), the span, z: z++ (then advance z), and t's color and highlight. If c is absent, add t without origin, with the span.
16. applyTextRangesDelta step 6: if holdsText and deleted.originalText === element.originalText, then for each non-retired t in inserted.textRanges?.ranges whose Map entry exists and is not retired, set that entry's start and end to t's, clamped. This restores exact offsets when no other text change came in between.
17. applyTextRangesDelta step 7: next = { textHash: hashString(nextText), ranges: canonicalizeTextRanges(Map values) }. If element.textRanges is undefined and ranges is empty return undefined. If areTextRangesEqual(next, element.textRanges) return element.textRanges. Otherwise return next.

### U05 — create `packages/element/src/textRangeLayout.ts` (codegen)

Behaviour: Maps style runs onto rendered lines without measuring, and lays one line's runs out as positioned pieces for canvas and SVG.

Rules:
1. Imports: hasRTLChars from @excalidraw/common; getTextStyleRuns from ./textRanges; types from ./types. No canvas or DOM use in this file: widths come only from the measure argument, so it stays testable and usable with a non-DOM canvas.
2. getRenderedLineOffsets, purpose: element.text is originalText with soft line breaks added, trailing whitespace dropped at soft breaks, and tokens of wrapped lines normalized to NFC. It returns, for each line of text, one source offset per code unit plus one final entry for the line's end.
3. getRenderedLineOffsets step 1: lines = text.replace(/\r\n?/g, "\n").split("\n"); p = 0. For each line, walk j from 0 while j < line.length.
4. getRenderedLineOffsets step 2: while p < originalText.length and originalText[p] !== line[j]: match /^[\s\S]\p{M}+/u against originalText.slice(p, p + 32). If it matches and line.startsWith(cluster.normalize("NFC"), j), push p once per code unit of the normalized cluster, add its length to j, add the cluster's length to p, and go back to step 1's loop. Otherwise, if originalText[p] matches /\s/, p += 1. Otherwise return null.
5. getRenderedLineOffsets step 3: if p >= originalText.length with j still < line.length return null. Otherwise push p, then p += 1 and j += 1. After the line, push p as its final entry.
6. getTextLineRuns step 1: runs = getTextStyleRuns(element); return null if empty. lineOffsets = getRenderedLineOffsets(element.text, element.originalText); return null if null, so a text out of step with its source renders unstyled, never wrongly styled.
7. getTextLineRuns step 2: for each rendered line, walk its code units with a pointer into runs (offsets never decrease). Group contiguous code units with the same color and highlight into { start, end, text, color, highlight }, where start and end are offsets into the rendered line and a unit in no run has color and highlight null. Never start a new group on a low surrogate (0xDC00 to 0xDFFF): it stays with the unit before it.
8. getTextLineRuns step 3: an empty line, or a line whose groups all have null color and null highlight, is null in the result, which means draw it as today. Return null if every line is null. The result has one entry per rendered line.
9. layoutTextLine step 1, directional segments: if direction is "ltr" and !hasRTLChars(line) there is one ltr segment. Otherwise classify each code point: rtl if hasRTLChars(char), ltr if /[\p{L}\p{N}]/u matches, else neutral. A maximal run of neutrals takes the class of the strong characters on both sides when they agree, else direction; a missing side counts as direction. Group consecutive equal classes into segments { start, end, direction }.
10. layoutTextLine step 2, visual order: walk segments in logical order for ltr and reversed for rtl, with x = 0. Each segment gets x and width = measure(line.slice(start, end)); x += width. The layout's width is the final x.
11. layoutTextLine step 3, pieces: for each run in logical order and each segment it overlaps, in logical order, take [a, b) as the overlap. In an ltr segment piece.x = segment.x + measure(line.slice(segment.start, a)). In an rtl segment piece.x = segment.x + segment.width - measure(line.slice(segment.start, b)). piece.width = measure(line.slice(a, b)), piece.text = line.slice(a, b), piece.direction = segment.direction, color and highlight from the run.
12. getTextLineLeft: "center" gives (elementWidth - lineWidth) / 2, "right" gives elementWidth - lineWidth, anything else 0.
