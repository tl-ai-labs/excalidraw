Behaviour: The preview layer behind the textarea: shows each run's colour and highlight, aligned with the textarea, and exists only while the element has visible runs.

Rules:

2. Exact constant: PREVIEW_CLASS_NAME = "excalidraw-wysiwyg-preview", exported.
3. Exact mirrored style keys, in this order, as a const array: position, display, minHeight, margin, padding, border, zIndex, wordBreak, whiteSpace, overflowWrap, boxSizing, backfaceVisibility, font, fontFamily, lineHeight, width, height, left, top, transformOrigin, transform, textAlign, verticalAlign, opacity. font comes before fontFamily and lineHeight, because setting font resets them.
4. update with an empty runs list: if the node is attached, remove it. Call editable.style.removeProperty("caret-color"). Return. The caller has already set the textarea's normal colour.
5. update with runs, step 1: create the node once, as a div with className PREVIEW_CLASS_NAME, aria-hidden="true", dir="auto", and fixed styles pointerEvents none, userSelect none, overflow hidden, background transparent, unicodeBidi plaintext (the textarea's dir="auto" makes each paragraph plaintext).
6. update with runs, step 2: copy each mirrored key from editable.style to the node's style. Set node.style.color = baseColor, editable.style.caretColor = baseColor, editable.style.color = "transparent".
7. update with runs, step 3: key = JSON.stringify([editable.value, runs, isDark]). When it differs from the last key, rebuild the children: walk runs over editable.value; text outside a run is a text node; a run is a <span> whose textContent is the slice, with style.color = applyDarkModeFilter(run.color, isDark) when color is set and style.backgroundColor = applyDarkModeFilter(run.highlight, isDark) when highlight is set. Use createElement, createTextNode and element.style only, never innerHTML.
8. update with runs, step 4: if the node has no parent, parent?.insertBefore(node, editable.parentNode === parent ? editable : null), so the textarea stays on top. Then syncScroll.
9. syncScroll: if the node exists, set node.scrollTop = editable.scrollTop and node.scrollLeft = editable.scrollLeft. It is an arrow function, so it can be assigned to editable.onscroll directly.
10. destroy: remove the node if attached and drop it.
