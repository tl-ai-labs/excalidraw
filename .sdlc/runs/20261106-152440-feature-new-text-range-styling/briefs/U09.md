### U02 — create `packages/element/src/textRanges.ts` (codegen)

Behaviour: Provide pure range algebra for normalizing, merging, splitting, applying, shifting on edit, querying, and line-projecting `TextRangeStyle` spans over `originalText`.

Rules:
1. 1. `isValidRangeColor(color: unknown): color is string` returns `true` iff `typeof color === "string"` and `color.trim().length > 0` and `color.trim().toLowerCase() !== "transparent"`.
2. 2. `normalizeTextRanges(ranges: unknown, textLength: number): readonly TextRangeStyle[] | undefined` returns `undefined` if `!Array.isArray(ranges)` or `textLength <= 0` or `ranges.length === 0`; clamps each entry's finite `start`/`end` integers into `[0, textLength]`, drops entries with `start >= end` or neither valid `color` nor valid `highlightColor`, splits overlapping intervals at all sorted unique boundary points so later entries override earlier entries per defined channel (`color` independently of `highlightColor`) while preserving the other channel from earlier entries, merges adjacent intervals that have `prev.end === curr.start && prev.color === curr.color && prev.highlightColor === curr.highlightColor`, omits undefined channel keys from each `TextRangeStyle` object, and returns `undefined` when empty.
3. 3. `areTextRangesEqual(a: readonly TextRangeStyle[] | undefined, b: readonly TextRangeStyle[] | undefined): boolean` treats `undefined` and `[]` as equal and returns `true` iff both arrays have equal length and identical `start`, `end`, `color`, and `highlightColor` at every index.
4. 4. `applyTextRangeStyle(ranges: readonly TextRangeStyle[] | undefined, textLength: number, start: number, end: number, style: { color?: string | null; highlightColor?: string | null }, baseStrokeColor?: string): readonly TextRangeStyle[] | undefined` clamps `[start, end)` to `[0, textLength]`; if `s >= e` or `textLength <= 0`, returns `normalizeTextRanges(ranges, textLength)`. Splits existing normalized ranges at `s` and `e`; when `"color" in style`, sets `color` on `[s, e)` if `isValidRangeColor(style.color)` and `(!baseStrokeColor || style.color.trim().toLowerCase() !== baseStrokeColor.trim().toLowerCase())`, otherwise clears the `color` channel on `[s, e)`; when `"highlightColor" in style`, sets `highlightColor` on `[s, e)` if `isValidRangeColor(style.highlightColor)`, otherwise clears the `highlightColor` channel on `[s, e)`; normalizes and merges the result via `normalizeTextRanges`.
5. 5. `computeTextEditDelta(prevText: string, nextText: string): TextEditDelta` computes common prefix length `start` and non-overlapping common suffix length `suffixLen`, returning `{ start, deleteCount: prevText.length - start - suffixLen, insertLength: nextText.length - start - suffixLen }`.
6. 6. `shiftTextRangesOnEdit(ranges: readonly TextRangeStyle[] | undefined, prevText: string, nextText: string): readonly TextRangeStyle[] | undefined` returns `undefined` if `!ranges?.length || nextText.length === 0`, or `normalizeTextRanges(ranges, nextText.length)` if `prevText === nextText`. Otherwise uses `computeTextEditDelta(prevText, nextText)` (`dStart = start`, `dEnd = start + deleteCount`, `dLen = deleteCount`, `k = insertLength`) to transform each range in two steps: first delete `[dStart, dEnd)` (`s1 = r.start <= dStart ? r.start : r.start >= dEnd ? r.start - dLen : dStart`, `e1 = r.end <= dStart ? r.end : r.end >= dEnd ? r.end - dLen : dStart`, dropping if `s1 >= e1`), then insert `k` at `dStart` (`s2 = s1 >= dStart ? s1 + k : s1`, `e2 = e1 > dStart ? e1 + k : e1`), and returns `normalizeTextRanges(shifted, nextText.length)`.
7. 7. `getStyleForTextRange(ranges: readonly TextRangeStyle[] | undefined, start: number, end: number, defaultStrokeColor: string): { color: string; highlightColor: string }` returns `{ color: defaultStrokeColor, highlightColor: "transparent" }` when `start >= end` or `!ranges?.length`; otherwise inspects normalized ranges overlapping `[start, end)` and returns a uniform `color` if ranges completely cover `[start, end)` with the same `color` (else `defaultStrokeColor`) and a uniform `highlightColor` if ranges completely cover `[start, end)` with the same `highlightColor` (else `"transparent"`).
8. 8. `projectTextRangesToLines(originalText: string, wrappedText: string, ranges: readonly TextRangeStyle[] | undefined): readonly (readonly TextLineRun[])[]` normalizes newlines (`\r\n?` -> `\n`) on both inputs, splits `wrappedText` on `"\n"`, advances a cursor `pos` through `originalText` to locate each line's `[lineStart, lineEnd)` offset in `originalText` (skipping soft-wrap trimmed whitespace via `originalText.indexOf(lineText, pos)` and advancing past at most one `\n` after each line), and slices each line `[lineStart, lineEnd)` against `normalizeTextRanges(ranges, originalText.length)` into contiguous `TextLineRun` segments `{ text, start, end, ...(color ? { color } : {}), ...(highlightColor ? { highlightColor } : {}) }`.
