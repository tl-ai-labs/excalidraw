### U03 — edit `packages/common/src/colors.ts` (codegen)

Behaviour: Adds `reverseDarkModeFilter`, which maps a dark-mode rendered colour to a light-theme colour that renders back to it, exact where the filter is injective.

Rules:
1. 1. No result cache of any kind: reverseDarkModeFilter is pure and does the same bounded work on every call.
2. 2. A private lazily built `number[]` table maps each invert-space value v to the smallest x in 0..255 with `cssInvert(x, x, x, 93).r === v`, filled once on first use by iterating x from 0 to 255; V_MIN is `cssInvert(255, 255, 255, 93).r` (18) and V_MAX is `cssInvert(0, 0, 0, 93).r` (237).
3. 3. `reverseDarkModeFilter(color)`: `const tc = tinycolor(color)`; if `!tc.isValid()` return `color`; read `{ r, g, b }` from `tc.toRgb()` and `alpha` from `tc.getAlpha()`.
4. 4. Canonical centre, solved from the hue matrix's linear relations (no search): `const vG0 = Math.round(0.426 * r + 0.43 * g + 0.144 * b)`, then `vR0 = vG0 + g - r` and `vB0 = vG0 + g - b` as exact integer offsets (never rounded separately); clamp each of the three to [V_MIN, V_MAX] with `clamp`.
5. 5. Candidates, in this order: the centre first, then the other 26 points of its +/-1 neighbourhood looping dR, dG, dB each over -1, 0, 1 (red outermost, centre skipped); skip a candidate with any coordinate outside [V_MIN, V_MAX]; for each, `const out = cssHueRotate(vR, vG, vB, 180 as Degrees)`.
6. 6. Return at the first candidate whose out equals (r, g, b); otherwise use the candidate with the smallest squared distance between out and (r, g, b), the earlier one winning ties.
7. 7. Bound (NFR-3): at most 27 cssHueRotate evaluations per call and no other loop over colour space; there is no fallback sweep, the result for clamped pixels (a 0 or 255 red or blue channel) comes from the same centre and neighbourhood.
8. 8. The result is `rgbToHex(table[vR], table[vG], table[vB], alpha)` for the chosen candidate.
9. 9. Never call applyDarkModeFilter and never read or write DARK_MODE_COLORS_CACHE; cssInvert, cssHueRotate and applyDarkModeFilter stay byte-for-byte unchanged.
10. 10. A short JSDoc above the export states the round-trip guarantee `applyDarkModeFilter(reverseDarkModeFilter(applyDarkModeFilter(c))) === applyDarkModeFilter(c)` and that the work is at most 27 hue-rotate evaluations.
